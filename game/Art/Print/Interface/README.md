# 远征手册界面资源

2026-10-13 使用内置 `image_gen` 生成并接入第一章。原始 PNG 保留生成分辨率；文字、数字和交互状态由 Godot 实时渲染。[完整生成词](prompts.json)。

## 资源

- `surfaces.png`：2 × 2 图集，依次为象牙纸面板、鼠尾草纸面板、普通按钮、朱红主按钮。
- `symbols.png`：6 × 4 透明图集，24 个 HUD / 导航 / 战斗图标。逐行顺序见生成词与 `ChapterSkin.Icon`。
- `sha256.txt`：交付原图校验值。

`ChapterSkin` 首次加载时将面板图集的每个区域归一为 128 × 128 的内存纹理，用 18 像素九宫格边距保持边框比例，避免高分辨率装饰挤占按钮文字。原始文件不被覆盖。图标直接使用带 `FilterClip` 的图集区域，线性采样并按语义着色。选中、悬停、按下、禁用和键盘焦点沿用原生按钮状态。

## 页面与文字

统一窗口由标题与页码、左侧七页导航、独立滚动的内容区、操作提示页脚组成。角色页按属性／穿戴／卡组组织；装备页按当前穿戴／可选装备／详情组织；物品页按随身／仓库或遗留物／取放操作组织。任务页分委托与旅途记录，整备页分随身装备与出征清单，工坊使用配方卡与底部制作按钮，地图与指引共享纸面体系。小于 1280 像素宽时，物品格位由四列切换为三列；筛选页签支持换行。

| 用途 | 字体与回退 | 字号 |
| --- | --- | --- |
| 页标题、分区标题 | 华文中宋 → 宋体 → Noto Serif CJK SC → serif | 28 / 20 |
| 正文、按钮、说明 | Microsoft YaHei UI → Microsoft YaHei → Noto Sans CJK SC → sans-serif | 16 / 14 |
| HUD 数值、资源指标 | Bahnschrift → Consolas → monospace | 20 / 28 |

字体由系统解析，不复制商业字体文件。中文正文始终使用中文字体；图标图集不含任何游戏文字。界面目前以 Windows 桌面为交付目标。
