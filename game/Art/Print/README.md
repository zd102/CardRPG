# 余火站 · 木刻插画美术

本目录是第一章当前使用的美术资源。2026-10-13 使用 `image_gen` 重新绘制场景、装备、角色与任务物，以木刻、剪纸和旧铁路海报为方向。原图保持生成尺寸，无降分辨率、模糊或后处理限色滤镜。

## 视觉约束

| 用途 | 颜色与处理 |
| --- | --- |
| 纸张与日光 | 暖纸色 `#e7dcc2`，为轮廓留出空间 |
| 轮廓、结构与文字 | 墨绿 `#253d3a` |
| 次要建筑与远景 | 鼠尾草绿 `#748777`、灰石色 `#b4b49a` |
| 暖色物件 | 赭黄 `#c39c53`，少量使用 |
| 焦点与操作 | 砖红插画 `#b65b47`；按钮使用较深的 `#a84c37` 保证文字对比度 |

六色是美术方向，并非强制量化为六种像素值。以大轮廓、两三层明暗和少量刻线控制细节；暗室保留深色变化，地点信息有独立纸签保证可读。禁止大面积高光、体积光、写实金属反射和堆叠装饰。图片不含游戏文字，标题、规则、数字和交互状态由 Godot 绘制。

`ChapterArt.cs` 缓存纹理与图集区域。角色图集按实际空隙切分，首行占高度 55.7%，第四列从宽度 74.3% 开始；装备与物件使用等分单元。图集保留透明通道，线性采样配合 `FilterClip`，避免邻格渗色。导入 `process/size_limit=0`，不限制尺寸。

`ChapterIllustration.cs` 绘制实物插画及图鉴标记。装备供牌使用可换行的小卡，消耗、效果、份数可直接比较；工坊以成品、材料、替换关系组织内容；任务卡展示对应物件；整备页展示随身装备和行囊。地图仅显示已发现地点的缩略图，仍不可点击移动。
