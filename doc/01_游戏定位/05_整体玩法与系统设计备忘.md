# 整体玩法与系统设计备忘

> 状态：暂存的发散设计，尚未定案，不代表全部采用或已实现。记录日期：2026-10-12。
>
> 讨论范围：装备驱动卡牌 RPG 的整体玩法与系统交互。以装备、肉鸽成长、刷装和搜打撤的结合为目标，不依赖特定剧情背景，也不以当前 Demo 的内容规模和实现方式为边界。

## 1. 核心设计目标

让玩家能够主动创造组合、改变局势，并持续发现已有装备、卡牌、敌人和奖励的新用途。

建议探索的系统关系是：**装备提供可组合的规则 → 战斗检验组合的使用方式 → 肉鸽奖励改变组合 → 玩家选择适合的风险 → 战利品在本局使用与长期保留之间取舍。**

以下八个方向是备选机制，其中包含可替代方案，不要求同时加入。当前只记录思路，具体数值、规则冲突与实现范围留待后续讨论。

## 2. 装备构筑：组合规则，而不只比较数值

装备分别承担产生资源、转换资源、利用资源和改变规则的功能，使同一件装备能够连接不同构筑。

| 功能 | 提供的能力 | 示例 |
| --- | --- | --- |
| 产生资源 | 建立可积累的优势 | 获得护盾、标记、充能、连击次数 |
| 转换资源 | 把一种优势变成另一种 | 消耗护盾获得行动点，消耗魔法强化攻击 |
| 利用资源 | 将积累兑现 | 按标记数量造成伤害，消耗充能爆发 |
| 改变规则 | 改变过程的条件 | 首次转换保留部分资源，过量部分转为防御 |

例如，“消耗护盾获得行动点”的装备可以与产盾装备形成连续出牌，与失去护盾时反击的装备形成转换伤害，也可以帮助高费武器提前释放重击。

玩家追求装备的理由因此可以是“它能连接我已有的两套机制”。构筑深度来自多种功能的相互作用，而不只来自同类伤害加成叠加。

资源返还、抽牌和复制等效果需要明确条件或触发次数。目标是允许有限而强烈的爆发，同时避免无成本无限循环。具体限制尚未决定。

## 3. 装备装配：结合随机获取与自主设计

可探索“掉落决定得到哪些组件，装配决定如何使用”的结构。

| 装配部分 | 作用 |
| --- | --- |
| 核心 | 决定主要能力和供牌 |
| 改造 | 改变费用、目标或触发条件 |
| 插件 | 连接某种资源或状态 |

同一攻击核心可以通过不同改造，偏向高费单次爆发、低费多次使用、以生命支付部分费用，或攻击已标记目标时扩散伤害。

不必采用复杂的格子拼装；少量可调整位置就可以先承载取舍。上述三类是功能划分示例，尚未确定槽位数量或是否全部采用。

继续保留装备完整供牌的特点：玩家改变装备结构，再由装备生成对应卡牌包，不直接从无限卡池挑选入组牌。替换时同时考虑失去的牌、加入的牌与整体费用；通过配置控制总牌量，避免穿戴越齐、核心循环反而越难形成。

不适合当前构筑的掉落可以保留给另一套装备、拆出组件，或现场消耗换取本局强化。拆解是否不可逆、何时允许改装、如何影响正在使用的卡组，均待确定。

## 4. 卡牌战斗：同时考虑资源分配与操作顺序

让一张牌的价值随手牌、敌人意图、剩余资源和执行顺序变化，增加计划空间。

| 决策维度 | 玩家思考的问题 |
| --- | --- |
| 顺序 | 先标记再攻击，还是先防御再转换资源？ |
| 时机 | 现在兑现优势，还是保留到下轮？ |
| 模式 | 用于进攻、防御，还是准备？ |
| 目标 | 攻击敌人，还是破坏它依赖的设施？ |
| 承诺 | 是否消耗防御能力，换取本轮击杀机会？ |

备选机制之一是少量双用途卡牌。例如正常使用造成伤害，也可以选择装填：本轮不造成伤害，让下一张武器牌获得额外效果。

另一个备选机制是有限的准备位：牺牲当前回合使用某张牌的机会，把它留到下一轮。随机抽牌继续提供变化，玩家则拥有主动组织组合的手段。

这些能力可由部分装备明确提供，避免所有卡牌都需要在多个模式间反复选择。准备位会涉及回合末全弃规则的例外，若采用，需要单独确定数量、代价与牌区关系；目前不改变已实现规则。

## 5. 敌人与战场：让同一套构筑产生不同用法

通过敌人之间、敌人与场景之间的关系，改变目标优先级和卡牌用途。

可考虑的关系包括：

- 一个敌人为其他敌人供能，处理供能者会改变局面。
- 某种敌方攻击可以被诱导去破坏障碍。
- 玩家与敌人可以争夺场上的共享资源。
- 击败某个单位会强化其同伴，击杀顺序有取舍。
- 部分战斗以取得物品或完成操作为目标，不要求杀光敌人。

例如“移动目标”这一效果，可以让敌人离开保护范围、进入危险区域或暴露身后的设施。同一个效果在不同关系下产生多种用途。

不同构筑应获得应对某类问题的优势，同时保留其他可理解的解法。避免大量硬性克制，将战斗变成是否携带指定装备的检查。

这里尚未决定采用格子战场、位置槽位还是抽象关系；应先明确希望产生的战术互动，再选择表现与操作方式。

## 6. 冒险配置：让玩家主动选择风险

将随机性与玩家的出征选择结合，给予有限的冒险配置空间：选择主要装备产出方向、接受额外挑战条件、交换准备便利，或确定互斥目标中的本局重点。

示例：

| 配置方向 | 对玩法的影响 |
| --- | --- |
| 更多精英、较少普通战斗 | 更强调应对强敌和单场资源使用 |
| 分散目标、更多搜索机会 | 更强调续航、路线与资源管理 |
| 携带特殊货物 | 让返程成为主要挑战 |

装备构筑可以影响玩家选择哪类冒险，反过来，不同冒险目标又能推动玩家准备第二套装备。玩家也可以主动接受不利条件，争取对应回报。

挑战条件应尽量改变决策，而非仅增加敌人生命来延长过程。收益与条件需要匹配，避免出现所有构筑都应选择的低风险高收益配置。具体条件池、奖励计算和解锁方式暂不确定。

## 7. 肉鸽成长：补足、放大与转向

随机奖励可以提供三类价值，使玩家既能完善原计划，也能产生新计划。

| 奖励类型 | 作用 | 对输出强、缺防御构筑的示例 |
| --- | --- | --- |
| 补足 | 改善缺点 | 攻击后获得少量护盾 |
| 放大 | 强化最擅长的事 | 提高爆发，同时减少恢复机会 |
| 转向 | 提供另一条路线 | 将部分攻击收益转为持续效果 |

选项应结合当前状态和后续目标产生不同价值，避免只有一个能用的选项，也避免每次精准投喂唯一正确答案。

可探索有条件的改造：先接受某项限制，通过符合要求的行为后升级效果。条件应引导不同打法，避免鼓励拖长战斗或重复无意义动作。

一次冒险可以同时提供“终于补齐”的满足和“这次换一种打法”的惊喜。临时效果如何叠加、哪些可以转为长期成果，以及出现节奏，均留待后续设计。

## 8. 搜打撤：战利品具有不同使用时机

在“继续深入还是撤离”之外，让同一件收获可以在不同时间尺度发挥作用。

| 使用方式 | 主要价值 | 放弃的机会 |
| --- | --- | --- |
| 保留并撤离收藏 | 长期装备与构筑进度 | 当前不能兑现它的全部临时价值 |
| 现场穿戴 | 增强本次冒险的战力 | 仍需承担未撤离损失风险 |
| 拆解成临时改造 | 解决当前困难或支持继续深入 | 失去这件装备的长期收藏价值 |

例如找到想收藏的装备，但当前生存压力很大。拆解可以换取临时优势，保留则更适合尽早撤离。是否允许现场穿戴仍取决于未来选定的换装规则，不能假定战斗中自由换装。

还可设置少量提前兑现机会：将一件战利品送回仓库，但消耗本次唯一的运输支援；同一份支援也能用于补给或开启出口。保护收获由此成为可规划的选择。

玩家需要知道可能失去什么、风险如何变化、还有哪些补救方法。这里暂不决定装备损失强度、运输次数或费用，不以增加惩罚替代有意义的风险选择。

## 9. 长期成长：持续增加可尝试的玩法

长期解锁可优先增加装备机制、组件、出征工具、冒险条件、改造分支、定向获取能力，以及保存和切换构筑的便利。

成长过程可以表现为：先掌握一套稳定装备，再为不同目标准备多套打法，最后利用收藏尝试以前无法成立的组合。

永久数值提升需要与本局成长共同控制。若基础攻击和生命不断膨胀，早期区域会失去风险，临时强化也可能被长期数值覆盖。

装备获取同时提供随机惊喜与可控进展：稀有掉落带来意外收获，重复材料则帮助玩家靠近自己选择的目标。具体经济规模尚未确定。

希望达到的结果是，成功一局后玩家能够自然提出“下一局想试什么”，而不完全依赖外部任务清单推动重复。

## 10. 系统连接示例

1. 玩家以获得护盾为基础出发。
2. 途中得到消耗护盾返还行动点的改造，开始关注高费攻击装备。
3. 面对两个奖励方向：稳定防御组件可以补足生存；范围伤害组件可以帮助挑战多敌人目标。
4. 玩家选择范围伤害，并因此改变本局的目标优先级。
5. 获得一件高价值装备后，选择现场拆解换取临时优势，或提前撤离用于下一套构筑。

这段示例只说明系统如何相互作用，所有具体物品、效果、收益和条件均未定案。

## 11. 后续讨论的边界

选择是否采用某项机制时，重点判断：它是否让已有装备、卡牌、敌人或奖励出现新用途，是否带来可理解的取舍，以及理解与操作成本是否合理。

需要后续收敛的主要问题：

- 装备采用固定整件、有限组件还是更自由的装配；是否允许现场调整。
- 双用途卡与准备位采用哪种形式，如何与抽弃牌、资源和装备来源规则衔接。
- 战场关系采用何种操作与表现方式。
- 冒险由玩家配置到什么程度，哪些部分保持未知。
- 临时强化与长期装备的边界，以及战利品现场消耗的成本。
- 长期数值成长、横向收藏与材料用途如何匹配。
