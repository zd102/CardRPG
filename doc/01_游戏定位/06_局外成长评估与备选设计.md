# 局外成长评估与备选设计

> 状态：整体玩法层面的设计评估与发散备选，尚未定案，未修改游戏实现。2026-10-12。
>
> 本文讨论跨远征保留的角色、装备、知识与出征能力；不以当前 Demo 的简化实现为设计上限，不引入剧情身份设定。

[返回概览](../00_游戏概览.md) · [整体玩法与系统设计备忘](05_整体玩法与系统设计备忘.md)

## 1. 局外成长应当带来什么

局外成长既需要让玩家感到积累有效，也需要保留每次远征的未知与压力。建议把收益分为四类：有上限的基础战力、更多可成立的构筑、更精确的追求目标，以及把本局发现转化为以后可尝试方案的能力。

长期收藏越丰富，本来就能更好地应对不同挑战，因此横向成长也有实际强度收益。不能仅把升级名称改成“选择”就认为不需要平衡。需要同时约束单次能携带的装备、技法和支援，避免所有解锁都直接叠加到角色身上。

以下“问题”是从已有设计关系推导的风险，不是已经完成玩家测试的结论。建议是可选替代，不能直接与原规则全部相加。

## 2. 需要重新审视的成长要素

| 要素 | 潜在不合理之处 | 更适合讨论的方向 |
| --- | --- | --- |
| 永久力量、敏捷、智力加点同时决定穿戴资格和战斗收益 | 稀有装备到手却不能试；跨流派改变需要重复刷取；速度收益还依赖行动顺序机制 | 据点可重配的资质预算，或明确采用另一种装备负载体系 |
| 力量加生命、敏捷加速度、智力加元素抗性 | 收益适用范围不同：生命通常广泛有效，元素抗性依赖遭遇，速度可能产生先手或行动次数跃迁 | 分开设计穿戴资格与基础生存收益，结合真实战斗机制验证，不先宣称三者等价 |
| 长期不断增加装备或护符槽位 | 同时增加属性、特效和供牌；多穿未必更好，卡组可能稀释 | 核心槽位早期开放，长期增加可选部件、改造和槽位用途 |
| 无上限生命、伤害、强化等级叠加 | 低级内容被数值碾过，失败容易被解释为刷取不足，局内变化被削弱 | 有限基础成长，后续以分支能力和新挑战为主 |
| 解锁装备全部进入同一个随机池 | 收藏越多，想找到的关键装备反而越难出现 | 开放图鉴与配方不等于强制进入所有掉落池，保留可追踪来源 |
| 永久收藏只有物品种类，重复物品只换材料 | 一次收集后目标容易耗尽；材料若只用于更高数字，重复劳动成为主要追求 | 可改造底材、玩法分支、有限工艺与确定性目标推进 |
| 局内所有发现只留下货币，临时组合结束即不可延续 | 本局创造的打法与下一局目标脱节 | 把组合记录为可研究的弱化常驻方案，或揭示对应装备来源 |
| 熟练度按使用次数或击杀数量升级 | 鼓励持续使用已熟悉装备，换流派意味着重新刷等级 | 有上限的能力解锁、不同用法试验和可替代的解锁路径 |
| 多种成长系统分别收费 | 加点、制作、洗词条、维修、支援共同争夺材料，试错变贵 | 明确材料用途层级，常规重配低成本，稀缺消耗集中于具体改造成果 |

装备永久保留、死亡不没收已有收藏，本身与本游戏的构筑试验方向相容。不能仅为了维持装备需求，就加入频繁报废或昂贵维修。重复追求应优先来自新的用途、组合和挑战。

## 3. 角色成长：资质成为配装方案的一部分

推荐讨论“总资质有边界，配置可在据点调整”的方式。角色获得一定资质预算，力量、敏捷、智力仍可决定装备资格，但加点随装备方案保存，出征时一起锁定。

这使取舍发生在同一次出征：想同时穿戴高需求的两件装备，就需要调整其他部分；收藏另一种装备，不代表角色永久失去使用它的可能。

免费重配本身并不能保证属性有意义。如果每次只是按目标装备的最低需求机械填点，且没有组合冲突，属性仍然只是换装手续。需要验证同一预算下是否存在多种值得选择的穿戴组合；若没有，应简化资格规则，而非增加更多重配操作。

角色早期可以获得少量基础生命或预算增长，形成清晰的成长感。随后应较早进入稳定区间，避免高级角色在相同配置下无限超过低级角色。区间和预算尚未给定。

对属性直接战斗收益有两个替代方向：保留但严格验证其价值，或将生命等基础成长与穿戴资质分开。尤其不能在速度机制未确定前，把一点速度、一点生命和一点元素抗性当成等价收益。

另一个更大的替代方案是装备负载：每件装备消耗装配容量，角色在固定容量内组合。若采用，需要重做穿戴需求规则，不建议再叠加完整力量/敏捷/智力门槛，形成两套含义重复的限制。

## 4. 技法成长：解锁可装配的操作方式

用少量可选择的技法改变出牌方式，而非让所有解锁永久常开。可设置有限技法位置，玩家在据点选择本次组合，数量待设计。

示例方向：

| 技法 | 提供的新选择 | 需要承担的代价或限制 |
| --- | --- | --- |
| 蓄势 | 保留一个由装备提供的牌副本到下一轮 | 本轮不能使用该牌，且需要明确准备位上限 |
| 变式 | 将指定装备牌切换成另一种合法使用模式 | 只支持标记了兼容性的牌，遵守对应费用 |
| 转换 | 用一种战斗资源支付另一种行为 | 每回合次数或转换效率有限 |

技法修改装备供牌的行为，不自动成为独立卡池。若影响回合末全弃、资源恢复或牌区流转，必须明确写成例外。

技法可以来自有限的挑战、研究或里程碑，但不通过反复打一百场同类敌人才获得基础功能。提供至少一种不要求玩家故意拖回合、挨打或使用不喜欢打法的替代解锁路径。

角色身份由本次采用的装备与技法共同表达。长期积累更多选择，单次装配仍有取舍。

## 5. 装备工艺：从等待完美掉落，转为经营自己的可用方案

建议将收藏理解为“可靠底材与已掌握工艺”，将稀有实物理解为“特别适合某种打法的版本”。核心玩法不应同时被底材、多个词条与高强化等级三重随机锁住。

一次成功带回新装备，可以开启其基础研究或来源追踪。基础复刻品能够实现该装备的主要玩法；稀有版本通过不同分支、词条组合或效率继续有价值。具体是否开放制造、复刻强度和材料成本需一起设计，防止一次获得后所有实物失去意义。

可优先考虑一种确定性的加工能力：保留底材和主要供牌，选择替换一个兼容的改造。玩家知道投入会得到什么，不需要连续掷骰直到成功。

研究首次获得的装备不应默认销毁唯一实物，尤其不能摧毁玩家正在使用的核心。需要消耗稀有样本的高级操作，应有明确预览和可选择的提交时机。

重复掉落可以提供通用加工进度或可提取部件。初期尽量减少货币种类，不让每个流派各自需要大量独立碎片。成本集中于获得新成果，普通配装重排不反复收费。

## 6. 构筑研究：把本局发现变成下一局的想法

这是较有辨识度的备选成长：记录玩家实际发现的资源循环，并提供把它转化为长期构筑分支的途径。

例如某次远征同时使用了产盾装备、消耗护盾的攻击与临时回能效果，形成连续出牌。结算时可记录这组关系，并提示一个研究方向：将“有限的消耗护盾回能”做成装备改造。

研究成果应是受约束的常驻版本：占一个改造位置、有触发次数或效率限制，不能把全部临时祝福原样永久叠加。下一局因此有一个新起点，也仍需要新的随机机会才能形成峰值表现。

识别可基于预先设计的机制标签与配方，不承诺自动推导任意组合。记录页面允许玩家自己收藏和命名方案，查看缺少的装备与已知来源，避免把个人发现全部变成系统替玩家给出的标准答案。

记录与授予奖励分开：发现关系可以留下笔记，但高级工艺需带回对应样本或完成明确目标。单次远征、单个机制对只登记有限进展，不按同一场内反复触发次数刷熟练度。

后续需要验证这种研究是否让玩家兴奋，还是增加一张不得不完成的清单。若玩家只是按配方要求凑动作，应缩减任务化条件，优先提供自由试验与来源线索。

## 7. 远征筹划：成长为更能掌控出发条件的玩家

局外解锁可以增加准备工具和获取情报的能力，但单次只能选择有限项，不能最终把所有未知与危险都消除。

可选择的准备方向包括：确定一种装备产出倾向、提前识别一项敌方条件、携带一次物资转运、预置一条撤离便利，或针对一个已知目标追加挑战。

例如情报、运输与补给共用准备位置：知道更多、带走更稳、战中更耐久之间形成取舍。具体位置数量未定；避免与装备负载、备用容量再叠加过多相似预算。

“已解锁”表示以后可以选择，不表示每次默认免费获得全部效果。常规使用已解锁工具不应都要求刷一种新消耗品，否则系统会变成出门前的采购劳动。

控制掉落的能力应有限且具体。选择某种目标来源或某类产出倾向，仍保留其他战利品和意外组合；不要让整局奖励完全围绕当前构筑精准生成。

## 8. 失败后的成长：保留理解，不把失败变成刷取捷径

永久装备和已确认知识可以保留，未撤离实物承担主要损失。还可以保存遭遇记录、组合笔记、缺失条件和失败时的关键状态，帮助玩家决定下一次怎样调整。

失败不应自动赋予越来越强的永久战斗加成，直到玩家靠数值通过；也不应让主动送死比完成目标更有效地解锁核心奖励。

知识与实物分别处理：可以记住见过一种能力和可能来源，但不能仅看见装备就直接解锁它的完整制造。若提供基础研究线索，需与成功带回样本的成果明确区分。

由此让失败后的下一次出发包含一个新的判断，而非仅重复相同流程攒经验。

## 9. 推荐讨论的整体结构

| 成长层 | 永久保留 | 出征时的约束 |
| --- | --- | --- |
| 角色基础 | 有限的基础成长与资质总量 | 资质分配随方案调整，本次锁定 |
| 技法库 | 已学会的操作规则 | 只装配少量兼容技法 |
| 装备与工艺库 | 收藏底材、部件、可用改造 | 穿戴、供牌与改造位置限制 |
| 构筑研究 | 组合记录与获得的研究分支 | 成果需要占用装备或技法位置 |
| 远征筹划 | 可用的情报、运输和准备选项 | 共享有限准备机会 |

不是要求同时实现五棵成长树。技法与构筑研究可以归入装备改造，筹划可以只提供少量服务；重点是保留各类收益的职责，减少重复货币与重复界面。

较明确的优先取舍是：保留有边界的角色成长；降低尝试新装备的重配成本；让收藏增加可用组合；让成功远征产生可追踪的新目标；通过出征配置控制累积优势。

若只选择一个较新的机制深入，可优先研究“局内组合记录 → 有代价的常驻改造分支”。它能把肉鸽的一次发现、刷装备的长期追求和撤离的样本价值连接起来。仍需验证其理解成本、配方规模和是否诱导机械刷取。

本文暂存设计评估，不替换已有属性、穿戴、绑定与存档规则。任何采用项都需要单独确定边界后再同步主文档。
