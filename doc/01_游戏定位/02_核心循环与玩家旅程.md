# 定位与核心循环

> 当前方案，2026-10-12。[返回概览](../00_游戏概览.md)

核心体验是“找到值得带走的装备，同时本局构筑足够强，让玩家想继续深入”。长期装备收藏与单次远征变化分别成立，撤离把二者连接起来。

2026-10-13 新增[背包管理](../07_奖励与经济/02_背包仓库与遗留物.md)与[消耗品](../07_奖励与经济/03_消耗品与补给.md)设计：出征选择背包、备用和补给，现场按格位挑选实物，剩余物留原位可同次回取，回营在有限仓库整理。玩家不仅决定何时撤离，也决定哪些收益值得占用空间；背包与负重已接入外环，高级消耗品仍待实现。

| 层级 | 玩家决策 | 保留范围 |
| --- | --- | --- |
| 长期成长 | 收集适合打法的装备，发现目标来源 | 仓库、绑定装备和情报永久保留 |
| 出征配置 | 选择供牌装备、背包容量、占格备用与消耗品 | 绑定装备失败保留；带入的普通实物仍有风险 |
| 收获管理 | 拾取、换物、留下回访，制作背包与扩建仓库 | 装入随身容器的物品才随撤离带回；图鉴不替代实物库存 |
| 本局成长 | 选择临时祝福、使用新装备、改变挑战条件 | 祝福结束清除，实物需要撤离 |
| 即时战斗 | 分配行动和魔法，选择攻击目标与防御 | 血量跨战保留，牌区按战重建 |

## 玩家旅程

1. 据点展示可用武器和完整供牌，选择铁锤或短杖，带固定护甲出征。
2. 区域地图展示路线、撤离位置和巡逻预警。先决定目标与退路。
3. 场景行动提供主动战斗、分步搜索、调查、工坊、祝福和设施操作。
4. 新装备可在工坊穿上，仍保留未撤离身份。比较整个卡组变化。
5. 继续深入可以挑战携带护腕的守卫，也可在入口或已通电货运站撤离。
6. 撤离绑定新装备、入库材料；重复装备回收。下一次远征重置地图局势和祝福。

## 原型取舍

场景采用地点连接与行动按钮。提交行动才推进敌人，没有现实时间操作要求。直接迎战选择时间和敌人；隐蔽接近需要付出行动；已到场的支援会影响编组。

原型用一个可回访区域验证关系，不做线性随机爬塔。固定地图降低学习成本，随机搜索和祝福提供变化。正式版可增加区域变体、定向掉落与额外事件，但不能只靠增加无决策的行动数延长流程。

第一局目标是理解预警、完成一场战斗并撤离。第二局尝试工坊、祝福、切警钟与首领。观察玩家是否真的因装备组合改变路线，而非永远按同一顺序清场。

## 待验证

- 持续生命和威胁升级能否提供适量压力。
- 首领奖励是否足以支持主动深入。
- 工坊换装是否有价值，普通战斗是否过长。
- 搜索中断与战败损失是否在操作前足够清楚。
