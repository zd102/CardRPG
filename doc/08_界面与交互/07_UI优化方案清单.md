# UI 优化方案清单：204 项

2026-10-15 · 对应 [深度复查与竞品对照](06_全界面深度复查与竞品对照.md) · 实施前基线 `cda7b29`。

本清单按玩家任务拆分。**修正**针对可定位的问题；**深化**是在已实现功能上改善体验；**新增**是审查时原版本范围之外的机会，不等同于缺陷。用户现已授权全部 204 项进入实施；逐项状态见 [实施记录](09_UI优化实施记录.md)。本页证据保留实施前基线，表中验收要求不因实现启动而自动通过。

优先级：**P0**＝关键内容或恢复操作被遮挡，下一轮首先处理；**P1**＝高频决策、误解或操作效率；**P2**＝清晰度、阅读、表现与低频效率；**P3**＝需要扩大平台、内容或存档范围的候选。优先级不代表工期，新增功能也不因编号靠前而自动进入开发范围。

**清单累计 204 项／32 组，代码已全部落地。** 操作便利性专项补充 A141–A188 共 48 项；管理页专项再补充 A189–A204 共 16 项，原编号保留。搜索、数量选择、快捷取放、配装预设等已有建议不重新计数。可阅读[便利性分析与竞品依据](#convenience)、[管理页新增条目](#management)、[管理页逐页方案与可视化判断](08_管理页操作与信息密度专项.md)及[实施顺序](#convenience-rollout)。后台验证范围见[实施记录](09_UI优化实施记录.md)；真实手柄／多屏设备验收和真人效率测量尚未进行，不能将代码完成等同于全部验收通过。

右键菜单、跨容器／装备槽拖拽、短悬浮与固定详情的职责、数量语义、取消及键盘替代路径已在[鼠标交互专项](08_管理页操作与信息密度专项.md#pointer-interactions)细化；对应 A086–A088、A143、A145、A184、A185，不新增重复编号。

[信息分层与精简](08_管理页操作与信息密度专项.md#information-disclosure)说明便捷操作落地后如何收起重复说明和低频按钮，并保留浏览、比较和执行所需的信息；本轮细化 A011、A064、A079、A099、A143、A184、A191，总数保持 204。

## 3. 文字、颜色和可读性（A015–A021）

`Text` 有阅读缩放，`Inline`、按钮、图块标题、地图绘字和悬浮说明多处固定字号。依据：[大字比较](../media/ui-deep-audit-20261015/rework-1100-150-comparison.png)、[大字仓储](../media/ui-deep-audit-20261015/rework-1100-150-storage.png)、[文字与说明实现](../../game/Scripts/ChapterGame.GraphicUi.cs)。

| 编号／级别／性质 | 观察或机会 | 优化方案 | 验收 |
| --- | --- | --- | --- |
| A015 · P1 · 深化 | 阅读字号不等于整个 UI 缩放，关键物品名仍固定 16 | 分设阅读字号与 UI 大小；先让对象名、数量和操作参与阅读模式 | 选大字后，不再需要靠小字识别正在解释的对象 |
| A016 · P1 · 修正 | 悬浮说明强制回到 16，地图标注固定 16／14 | 说明层与地点文字遵循对应字号策略，增大时重算边界 | 大字说明完整、不裁尾、不越屏 |
| A017 · P2 · 修正 | 指引原图出现 20 与 kg 分行、末尾标点单独落行 | 数字＋单位使用不可拆分的短语布局，调整中文换行与段宽 | 关键费用、重量和括号说明不产生歧义 |
| A018 · P1 · 深化 | 朱红同时承担主按钮、焦点、选中目标和危险 | 焦点用独立外框，选中用勾选或边标，危险增加图标和后果词 | 无颜色条件下仍能区分三种状态 |
| A019 · P2 · 深化 | 背包、锁、回合等图形在不同位置复用多种含义 | 建立语义图标表；手部空槽、未解锁、容量等有不同轮廓或标签 | 同一图标不会在相邻区域表达相反含义 |
| A020 · P2 · 深化 | 常用正文配色不应仅凭感觉继续加深；纹理背景也影响阅读 | 做真实背景上的对比检查，优先修关键文字／状态边界；保留装饰层次 | 达到选定对比目标，并记录实际取色位置；不把禁用态当正常正文 |
| A021 · P3 · 新增 | 中文文案直接写在布局代码中，尚未验证扩展语言 | 提取显示文案与格式，先做长文本压力验证，再决定多语言范围 | 增长约三成的名称和规则仍可完整阅读 |

## 操作便利性专项：先减少寻找、往返和重复准备

**建议优先让玩家在一个稳定上下文中完成“找到对象 → 看清后果 → 执行 → 处理下一项”。** 单纯增加快捷键，无法解决选错库存批次、按钮远离对象、操作后丢失焦点、物资整理后又要逐个取回等问题。评估每个方案时，分别记录操作次数、跨页次数、指针移动、状态记忆、等待和误操作恢复；不把“少点一下”直接等同于更好。

本次重新阅读页面导航、库存、制作、热点和战斗输入实现，并复用同一源码版本的正式截图。以下新发现属于**源码证据**：打开普通／嵌套页时统一请求关闭按钮焦点；热点文字画在按钮矩形之外；通用按钮在战斗回放期间拒绝回调。中文输入法、连续点击穿透、手柄切换等是新增交互需要预防的风险，**未宣称当前已复现**。真实可用性仍需要按文末流程验证。

### 把“方便”落到完整任务上

以下是**基于源码的流程推演与设计目标**，没有真人耗时数据。一次激活指点击按钮／物品，或等效的确认键；文字输入、滚动、打开批量模式和确认弹窗需要单独计入，不能藏进“一键”里。现有的整批移动、材料一键归仓、制作材料汇总、返回恢复部分状态都已存在，优化应建立在这些能力上。

| 代表任务与起点 | 当前路径／成本来源 | 建议路径 | 判断是否值得实现 |
| --- | --- | --- | --- |
| 战斗中打一张牌，当前无选择 | 默认目标可用时，选牌＋确认已可为 2 次激活；换目标通常再加 1 次。主要问题是跨屏确认和键盘衔接 | 选牌后在手牌附近预览；方向键选目标，明确确认，再回到有效手牌 | A050、A057、A166：保持后果可读，减少指针往返；不把现有流程夸写成四五次点击 |
| 营地转移 5 个任意指定批次，均在视野内、空间足够、初始无选择 | 若逐项选中并点整批移动，需 5×2＝10 次激活；已有“全部材料归仓”不属于这个例子 | 勾选 5 项＋执行＝6 次；如需进入批量模式则为 7 次，额外确认另计 | A147：用户能核对选择，不误带其他物品；不能将此数字套用到已有一键材料归仓 |

| Shift 快移 | 如采用 A087，仅在合法范围内执行可预期的快移；野外保留费用与风险预览 | 同时被多选范围占用，或省略了本来需要的行动次数 |

| Space 结束回合 | 只在有效战斗输入上下文使用；有局部编辑／弹窗时由其处理 | 查看说明、输入文本或跨页时意外结束回合 |
| 只读查看 | 不移动、不扣材料、不触发巡逻；明确当前值与回放历史 | 页面快捷入口绕过营地／野外权限，或无意延长免费拾取窗口 |

### 建议的验证任务与记录方法

先对 A078 物品对象、A057 出牌状态、A127 浮层归属建立统一契约，再评估快操作。批量移动、撤销、批量交付涉及持久状态，需要有意义的规则测试；纯文案、位置和提示调整主要检查实际渲染与输入路径，避免用大量镜像实现的测试代替体验检查。

| 验证任务 | 必测分支 | 记录什么 |
| --- | --- | --- |
| 打两张指定牌后结束回合 | 鼠标／键盘；同目标／目标死亡；回放中查看；取消选牌 | 激活和跨区次数、错误目标、焦点归宿、等待、是否额外提交 |
| 移动指定三件和五种物品 | 同名不同批次；容量不足；有保留标记；筛选隐藏已选；保存失败 | 实际对象与数量、遗漏、回退次数、恢复成本；与已有材料归仓分别计数 |
| 回营后按目标补给并部署 | 缺货、临时配发、负重超限、预设缺件、切到非法访问地点 | 重复找物品次数、页面往返、自动替代／意外出发是否发生 |

| 热点与弹窗边界 | 点文字边缘、邻近热点、1100 大字、连续点击、长按确认 | 错误命中、遮挡、穿透、需要的额外操作；功能测试不能代替截图 |

每次从相同存档副本和固定起点运行；按 1100×760、1280×800、1600×900 及适用字号记录。已有截图只覆盖其实际场景，不能据此宣称全部大字号组合都通过。后台自动验证完成后，真人试用再记录完成率、误操作和主观理解；这次分析没有填入虚构的耗时或成功率。

## 如何选一轮范围

先落实 A127、A134 两项遮挡，再处理 A113、A029、A078 的状态和对象语义。随后围绕“打一张牌、移动指定数量物品、看一个地点”三个动作选择相邻条目做完整闭环。不要按编号机械顺序执行，也不要一次把 204 条都加进界面。

跨条目依赖：A078 物品选择单位先于 A085–A090 快捷取放；A015 字号策略先于所有大字版布局；A057 输入状态先于 A058 拖牌与 A137 改键；A113 阶段一致先于 A114 任务追踪；A127 浮层归属先于 A132 叙事演出。共用组件的改动应覆盖相关页面，避免分别打补丁后再次出现不同语义。

便利性专项建议分三轮，并按结果决定是否继续扩展：

| 轮次 | 可交付的完整体验 | 范围与取舍 |
| --- | --- | --- |
| 第一轮：操作衔接 | 从打开页面到执行下一项不迷失；场景标签确实可点；战斗目标和确认稳定 | A141、A142、A145、A166、A171、A177、A180、A188；结合原 A057、A078。优先修现有路径，记录自然输入基线 |
| 第二轮：营地整理 | 指定数量、多选、保留量、空间不足和返回整备形成闭环 | 原 A085–A089，加 A143、A147–A151、A153、A157；先营地，独立验收保存回滚和选择一致性，再讨论野外适用部分 |
| 第三轮：长期重复使用 | 配装差量、材料计划、固定入口与信息查看 | A154–A156、A158–A164、A167–A170、A182–A187；仅保留被试用证明有价值的配置项。A179 撤销和 A178 批量交付单独评估状态复杂度 |

新增依赖：A147 多选先于 A151 隐藏选择；A148 携行保护先于 A149 规则归仓；A035 预设身份和 A078 批次身份先于 A153–A156；A160 消耗来源先于 A161–A164 材料规划；A181 拾取边界先于任何野外快捷整理；A144 输入层级先于搜索、数量编辑和菜单快捷键；A146 命令去重应覆盖所有执行入口。最终目标是少找、少往返、少重做，同时让规则和后果始终可见。

管理页专项可先独立试做仓储＋角色卡组：A078 对象统一 → A189／A190 空间重分配 → A193–A195 数值与预测；A064 紧凑卡表 → A196 明确详情 → A197／A198 来源与范围。随后处理 A099 改装选择比较、A201 背包表，再做 A199／A202 制作与交付后果。完整取舍和验收见[管理页专项](08_管理页操作与信息密度专项.md)，不要求先实现所有便利性新功能。
