# 界面与操作

> 当前桌面中文 Demo，2026-10-12。[返回概览](../00_游戏概览.md)

默认 1280×800，窗口最小 1100×760；长内容可滚动。使用系统中文字体、暗色工业风、原生 Godot Control。正文 16，局部标题 21，主标题 28。

## 页面

| 页面 | 主内容 | 主要操作 |
| --- | --- | --- |
| 据点 | 装备供牌、仓库和下一次远征目标 | 选择武器、出征 |
| 区域 | 路线、当前场景、预警、行动成本、最近反馈 | 点击相邻地点或场景行动 |
| 战斗 | 公开敌人意图、选中目标、手牌、资源和牌堆数量 | 选敌、出牌、结束回合、撤退 |
| 祝福 | 两个具体效果 | 二选一 |
| 装备 | 持有装备、供牌、完整卡组、未入库收获 | 合法地点换装，否则只读 |
| 结算 | 带回或损失的具体收获 | 回据点 |
| 指引 | 一次远征的三个决定 | 免费查看、返回 |

I 打开装备，F1 打开说明，Esc 关闭这些页面。按钮支持 Tab 聚焦，Enter/Space 操作。鼠标点击按钮即可完成整个远征。没有 WASD 移动或实时攻击。

无效地点、已完成交互、资源不足的牌禁用；行动描述仍可见。预警同时使用颜色和文字，地图用“●”标识当前位置。卡牌给出资源费用、效果和装备来源。

## 反馈原则

操作提交后刷新状态与最近消息，思考期间不出现倒计时。搜索每步单独按钮，显示噪声与被打断后果。准备牌只占首回合五张之一。危险撤退按钮显示承受攻击的条件。

战利品保持“未撤离”身份，装备页也显示这一身份。保存失败用持续消息展示，不只写日志；退出按钮必须在保存成功后退出。

当前没有游戏音效、复杂动画、读屏实测或字体缩放设置。后续可在不改变规则节奏的前提下增加行动短动画；不使用动画时长推进世界。
