# 界面与操作

> 第一章外环，2026-10-14 UI 重组。[返回概览](../00_游戏概览.md) · [22 组建议落实记录](04_UI重组实施与验收.md)

默认入口为 Chapter.tscn，采用木刻、剪纸与旧铁路海报风格的全屏场景与悬浮 HUD。探索时点击物件和相邻出口，场景不预留固定右侧栏或底部操作面板。角色、装备、整备、任务、制作、地图和指引按需居中展开。

默认窗口 1280×800，最小 1100×760，stretch 为 disabled，使用原生像素布局并按窗口重排。背景按覆盖方式裁切，位图使用线性采样。管理页使用距屏幕边缘 12 像素的工作区，顶部统一导航；库存常显穿戴、随身与仓库三栏。操作区域使用平面底色和细分隔，版画风格保留在场景、物品与地图。规则和详情阅读字号可调为 16／20／24，目录与图标保持紧凑。布局依据与实机留档见[搜打撤布局修正](05_搜打撤布局修正.md)。

## 页面

| 页面 | 主内容 | 主要操作 |
| --- | --- | --- |
| 据点 | 余火站全景、工作台、任务交付、行前整备与出征入口 | 点击场景标记；交付后出现投影、维修偶和居民衣架 |
| 整备 | 左侧穿戴、中间部署地图、右侧清单与固定最终状态 | 选择初始工具、补给和入口；检查负重、容量及返还预留后部署 |
| 区域 | A01～A07 的物件、出口、压力和最近撤离提示 | 点击物件执行行动，通过相邻出口移动 |
| 地图 | 已揭示的地点、道路、当前位置及未开放分区提示 | M 打开，只读查看；Esc 返回 |
| 战斗 | 敌人、生命与公开意图、下方手牌与资源 | 选牌预览，选择目标后确认；右下结束回合或预览撤退 |
| 共鸣／列车奖励 | 场景入口与互斥选择面板 | 自由比较、取消或确认；明确本次仅选一项 |
| 试用 | 工坊背景、练习靶、借用牌组与完成提示 | 实际出牌体验组合，随时结束试用 |
| 角色全览 | 当前属性、四部位穿戴、完整卡组与装备来源 | C 打开；点击部位或库存入口调整，Esc 返回全览 |
| 装备 | 左侧常显穿戴、中间候选装备、右侧供牌比较 | 对比副本增减和费用，再穿戴／携带备用 |
| 物品与仓库 | 穿戴、随身、仓库／地面三栏；底部窄操作条 | 单件／整批取放；按占格排列、显示空位；部分拾取先确认清单 |
| 任务 | 目录与详情、常显下一步、分类日志与发现回顾 | 默认进行中，可交付优先；在据点交付 |
| 制作与改装 | 已开放配方、材料需求、改装方案 | 明确点击制作或改装，材料不足时禁用 |
| 结算 | 本趟带回／净增加／实际损失、遗留地点、永久变化 | Enter 或按钮回营；可交付任务承接下一步 |
| 系统 | 阅读字号、减少动态、声音、标签与提醒 | Esc 打开；继续、操作说明、保存退出 |
| 指引 | 章节操作、存档与风险说明 | F1 打开，Esc 返回 |

C 打开角色全览，M 打开地图，I 打开装备，J 打开任务，F1 打开指引。Esc 优先返回当前覆盖层或取消选牌，在场景中打开系统菜单。Tab 聚焦、Enter 激活；选牌后左右方向键切换目标。战斗中 Space 始终请求结束回合，不与聚焦手牌的激活冲突；仍有可用手牌时默认提醒，可在设置关闭。物资页 Shift+Enter 对所选批次执行整批取放，费用与按钮一致。查看与取消不推进压力。

## 场景与反馈

探索仅显示已揭示的相邻出口。目标条给出具体动词，关键物件及出口常显标签；设置可开启全部标签。标签避让包括文字范围，移位后用引线关联物件。结果通知位于底部，完整说明位于其上方；管理页提示靠近所属对象，返回按钮不再弹出宽说明条。巡逻抵达明确说明可以离开，战斗思考不推进压力。

任务进度映射到场景：继电器交付后点灯投影，维修偶救出后离开废料台，工坊熄灯后显出荧光暗门，货站修复后通电。S07 与 S09 交付后，据点分别增加维修偶与居民衣架。这些变化随永久进度保存。

卡牌显示费用、牌名、动作徽记与效果。选中后在手牌附近展开真实规则预览，再明确确认；穿盾、耗盾、共鸣和抽牌上限共享规则层计算。不可用牌仍可聚焦查看原因。战术撤退先显示预计损血、返回地点和致死后果，取消不改变战斗。结算按真实敌方顺序回放文本并短暂强调对象，配有可关闭的合成音效和减少动态选项。战斗胜利先展示地面战利品，再进入装包。

同页刷新保留局部滚动，嵌套返回恢复入口焦点、滚动位置和装备分类。键盘聚焦只滚动所属区域。保存失败显示持续错误并回滚本次规则操作；退出时必须先保存成功。关键首次救援、点灯、修复和交付有可跳过纸签，并可在发现记录回顾。

## 角色、装备与库存

角色页顶部展示实际生命与战斗资源、卡组总量和攻防／抽牌构成，下方为穿戴摘要与紧凑牌表。牌表合并副本并标注费用、效果、来源；战斗中统计手牌、抽牌堆和弃牌堆，试用显示借用构筑。阅读不消耗资源或改变随机序列。

装备页采用左侧常显四部位穿戴、中间候选目录、右侧对比。变化明确列出移除与加入的副本数、费用和规则，底部固定真实换装后的负重／格位和操作。制作页复用对比，以实际可用材料显示拥有／所需数量；改装逐行展示基础副本和改装副本，只替换一张。

物品页默认打开物资管理，穿戴栏宽 208～232 像素，随身与仓库分配其余空间，局内最右栏改为地面物品。物件按统一格位排列，双格为连续宽块；未筛选时显示实际容量对应的空格背景。提供网格／列表和分类筛选，批次保留配发、登记、校准区别；底部窄条给出来源、去向、整批后负重和行动值。容器独立滚动，选择物件不弹出覆盖周围格位的宽提示。部分拾取先列明装入／留下清单，以一次取放结算，巡逻仍可打断。基地可批量存入材料。

空装备位、未解锁手部、满包、超重和空仓均有文字状态。超重同时显示负重条与“场景行动值 ×2”；放弃库存物品仍需明确确认。工坊提供背包、密封补给与仓库扩建。当前仅实现 U01 补给；战斗消耗品、多种药剂、任意数量输入和拖拽整理仍属后续设计，见[背包实现](../13_第一章_余火铸造区/10_背包与负重实现.md)。
