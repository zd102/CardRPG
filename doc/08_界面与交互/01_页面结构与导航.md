# 界面与操作

> 第一章外环，2026-10-13。[返回概览](../00_游戏概览.md)

默认入口为 Chapter.tscn，采用木刻、剪纸与旧铁路海报风格的全屏场景与悬浮 HUD。探索时点击物件和相邻出口，场景不预留固定右侧栏或底部操作面板。角色、装备、整备、任务、制作、地图和指引按需居中展开。

默认窗口 1280×800，最小 1100×760，使用 canvas_items / expand 适配。背景按覆盖方式裁切，交互标记与据点道具共享场景坐标变换；调整窗口尺寸会重新排布。文字、按钮、生命与意图由原生 Godot 控件绘制，保持清晰；位图采用最近邻采样。

## 页面

| 页面 | 主内容 | 主要操作 |
| --- | --- | --- |
| 据点 | 余火站全景、工作台、任务交付、行前整备与出征入口 | 点击场景标记；交付后出现投影、维修偶和居民衣架 |
| 整备 | 当前装备、备用、起始武器与出发地点 | 选择装备、显式携带仓库夹具，从入口或已开放的货站出发 |
| 区域 | A01～A07 的物件、出口、压力和最近撤离提示 | 点击物件执行行动，通过相邻出口移动 |
| 地图 | 已揭示的地点、道路、当前位置及未开放分区提示 | M 打开，只读查看；Esc 返回 |
| 战斗 | 透明敌人角色、生命与公开意图、悬浮手牌 | 点击角色选敌，点击卡牌出牌；右上角结束回合或撤退 |
| 共鸣 | 工坊中的场景交互点 | 查看提示，选择本趟共鸣 |
| 试用 | 工坊背景、练习靶、借用牌组与完成提示 | 实际出牌体验组合，随时结束试用 |
| 角色全览 | 当前属性、四部位穿戴、完整卡组与装备来源 | C 打开；点击部位或库存入口调整，Esc 返回全览 |
| 装备 | 四部位装备板、可选装备图鉴、供牌详情 | 先点部位或装备，再穿戴／携带备用；据点或已启动的台架可换装 |
| 物品与仓库 | 随身格位、仓库或现场遗留物、选中物品详情 | 按单件或整批取放；双格装备展示续格，空格显示编号 |
| 任务 | 主线、支线与已发现内容 | 查看进度，在据点交付满足条件的任务 |
| 制作与改装 | 已开放配方、材料需求、改装方案 | 明确点击制作或改装，材料不足时禁用 |
| 结算 | 撤离收获或战败损失、仓库统计与永久保留进展 | 返回余火站 |
| 指引 | 章节操作、存档与风险说明 | F1 打开，Esc 返回 |

C 打开角色全览，M 打开地图，I 打开装备，J 打开任务，F1 打开指引，Esc 关闭覆盖层。按钮支持 Tab 聚焦与 Enter 操作；战斗场景支持空格结束回合。查看地图、装备和说明不推进区域压力。鼠标可以完成整个远征，没有 WASD 移动或实时攻击。

## 场景与反馈

探索仅显示已揭示的相邻出口。交互标记提供悬停提示，说明行为、费用与后果；条件不足时禁用，完成后按实际状态移除或替换。操作结果在上方短暂显示后淡出。巡逻抵达时以文字说明可以离开，战斗思考不推进场外压力。

任务进度映射到场景：继电器交付后点灯投影，维修偶救出后离开废料台，工坊熄灯后显出荧光暗门，货站修复后通电。S07 与 S09 交付后，据点分别增加维修偶与居民衣架。这些变化随永久进度保存。

卡牌显示行动／魔法费用、牌名与效果；悬停可看完整效果、装备来源和不可用原因。手牌按张数与窗口宽度居中排布，额外抽牌后仍保持可见。出牌后保留存活目标，目标倒下时切换。敌人增援时重新排布角色和公开意图。

同一覆盖层刷新保留局部滚动位置，换页回到顶部；键盘聚焦只滚动所属内容区。战利品明确区分未入库与已登记。保存失败显示持续错误消息；退出时必须先保存成功。

## 角色、装备与库存

角色页左侧展示实际生命、行动、魔法、护盾、补给、负重和生效共鸣；中间为武器、身体、手部、背包四个部位；右侧展示完整卡组，合并同名副本并标注数量、费用、效果和装备来源。战斗中以手牌、抽牌堆、弃牌堆的实际副本为准；台架试用显示借用构筑。未进入战斗时展示当前穿戴所提供的卡组与每回合基础资源。阅读不消耗资源或改变随机序列。

装备页按“当前穿戴 → 可选装备 → 选中详情”组织。点部位可筛选对应装备；供牌、重量、库存位置和穿戴／备用操作都随选择更新。背包详情给出口袋加背包的总容量。

物品页将随身和仓库并排显示；局内第二栏改为当前位置的遗留物。格位按真实堆叠上限计算，同类、同配发状态、同校准状态的来源批次共享容量。每个格位均可选择，双格装备第二格注明“占位”；选择后在详情区按来源批次操作，避免混淆任务物或免费补给。仓库和行囊独立滚动，取放后更新空位、数量和负重。格位自动整理，目前无需拖拽或空间拼图。

空装备位、未解锁手部、满包、超重和空仓均有文字状态。超重同时显示负重条与“场景行动值 ×2”；放弃库存物品仍需明确确认。工坊提供背包、密封补给与仓库扩建。当前仅实现 U01 补给；战斗消耗品、多种药剂、任意数量输入和拖拽整理仍属后续设计，见[背包实现](../13_第一章_余火铸造区/10_背包与负重实现.md)。
