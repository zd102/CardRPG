# 界面与操作

> 当前桌面中文 Demo，2026-10-12。[返回概览](../00_游戏概览.md)

采用**单区域场景 + HUD**：行动页一次只显示当前地点，行为位于场景物件旁，相邻区域以边缘出口呈现；没有右侧行动栏。全区域视图独立为只读地图。默认 1280×800，窗口最小 1100×760，使用 canvas_items / expand 适配。场景行为与出口不需要滚动，长内容仅在出征装备列表和装备／指引覆盖层内滚动。

使用系统中文字体、炭黑与雾青工业风、半透明 HUD、琥珀色主要按钮和原生 Godot Control。正文 16，局部标题 21，主标题 28，场景展示标题 38–48；辅助标签 12–13。

## 页面

| 页面 | 主内容 | 主要操作 |
| --- | --- | --- |
| 据点 | 全景铸造区；左侧远征目标与右侧整备 HUD | 选择武器；出征按钮固定在整备面板底部 |
| 区域 | 当前地点的独立场景、物件交互点、边缘出口、底部说明与反馈 | 点击物件旁的行为执行；通过相邻区域出口移动 |
| 地图 | 完整六地标与道路、当前位置、相邻关系、货运站供电状态 | 只读查看；没有移动或场景行动；M / Esc 返回 |
| 战斗 | 完整战场与敌人角色；生命与意图悬浮在角色附近；底部手牌 HUD | 点击角色或名称选敌，出牌、结束回合、撤退 |
| 祝福 | 全屏回响装置与底部两个并列选项 | 二选一 |
| 装备 | 保留场景背景的覆盖层；装备、卡组条目与未入库收获 | 合法地点换装，否则明确标为仅可查看 |
| 结算 | 场景上的结算 HUD，区分成功／失败、收获摘要与仓库统计 | 回据点 |
| 指引 | 场景上的手册覆盖层，三个决定与战斗速查 | 免费查看、固定关闭按钮返回 |

M 打开地图，I 打开装备，F1 打开说明，Esc 关闭这些页面。按钮支持 Tab 聚焦，Enter/Space 操作。地图、装备、指引互斥显示；打开、关闭或点击地图均不消耗行动。鼠标点击场景按钮即可完成整个远征。没有 WASD 移动或实时攻击。

行动页只出现合法相邻区域的出口，不显示非相邻移动按钮。已完成或条件不足的交互禁用，并显示具体状态。物件旁同时显示行为、费用或关键后果；悬停或键盘聚焦时，底部说明区显示完整后果，不改变游戏状态。预警同时使用颜色和文字，锁定时明确提示拦截风险。

六个地点分别绘制营地、货运广场、废料场、工坊、熔炉和升降站的环境。物件、行为标注和出口使用共享坐标，缩放时保持对齐。地图用“●”与建筑轮廓标识当前位置，地标名称使用非交互标签；点击标签或地图背景不会移动。

卡牌给出资源费用、效果和装备来源，不能使用时显示“资源不足”。手牌保持五个布局位置，不随剩余张数拉宽；出牌后保留选中的存活目标，目标倒下时自动切换。手牌、回合操作和撤退始终处于屏幕底部。同一内容刷新保留局部滚动位置，换地点或切换覆盖层回到顶部；键盘聚焦仅滚动所属内容区。

页面截图见[界面预览](../media/ui-preview.html)。验证覆盖六个独立区域、只读地图、其余页面、战败状态、完整装备收藏和多敌人战斗，检查默认窗口及 1100×760、1600×900 的布局。逐个点击地图地标后比较完整远征状态，确保没有移动或步数变化；检查仅显示相邻出口，所有场景按钮可见、互不重叠，说明区不遮挡行动。

## 反馈原则

操作提交后刷新状态与最近消息，思考期间不出现倒计时。搜索每步单独按钮，显示噪声与被打断后果。准备牌只占首回合五张之一。撤退按钮下方始终显示承受攻击及损失条件。

战利品保持“未撤离”身份，装备页也显示这一身份。保存失败用持续消息展示，不只写日志；退出按钮必须在保存成功后退出。

当前没有游戏音效、复杂动画、读屏实测或字体缩放设置。后续可在不改变规则节奏的前提下增加行动短动画；不使用动画时长推进世界。
