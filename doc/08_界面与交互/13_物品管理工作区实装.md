# 物品管理工作区实装

日期：2026-10-16。范围：背包、仓库、穿戴、装备比较，以及营地取放和野外拾取。

## 这次解决的问题

上版实际界面仍把玩家的任务拆成了物资管理、装备比较和常驻详情三个区域。仓库只能显示较窄的清单，穿戴入口缺少物品形象；看见一件背包后还要换页才能穿戴。同一种材料按历史来源反复出现，也增加了寻找和判断的负担。

本版把主界面改为两个物品区域：左侧是穿戴和随身背包，右侧是仓库或附近物品。随身物品采用带图标的短清单，为四个穿戴槽留出位置；仓库默认采用物品图块。当前选中物品的用途、变化和操作放在底部。玩家先找到物品，再决定取放或穿戴。

## 已实现的交互

| 玩家任务 | 本版行为 |
| --- | --- |
| 判断正在穿什么 | 四个带图像的穿戴槽显示部位、名称、已穿戴／空槽／未解锁状态。 |
| 查找可替换装备 | 点击穿戴槽，在当前物品区筛选同部位候选；清除筛选恢复全部。 |
| 穿戴仓库中的装备 | 选中图块，底部直接显示穿戴操作、负重变化、背包容量或供牌差异。 |
| 深入比较卡组 | 主动打开详细比较，返回后保留原物品、筛选和阅读位置。 |
| 拖装备到部位 | 正确部位原地展示候选，需再点穿戴；错误部位不执行。 |
| 查找与整理材料 | 默认图块及同状态合并显示；提供搜索、排序、清单和紧凑布局。 |
| 精确取放数量 | 合并物品的数量面板支持跨来源批次取放，并显示容量、负重和超重后果。 |
| 查看来源或单独操作一批 | 展开来源批次，选择准确批次；整理工具可恢复合并显示。 |
| 快速取放 | Shift+点击、Shift+Enter、拖放；营地取放可一次撤销。 |
| 批量处理 | 主动进入多选后才显示勾选框；批量操作沿用明确预览、保护和确认。 |
| 野外拾取 | 随身物品与附近来源并置，保留实际行动／压力费用与装不下时的选择。 |

常规尺寸固定穿戴区；较大字号和较矮窗口允许左侧整体滚动。底部操作和工具区可横向滚动并跟随键盘焦点，避免把所有按钮挤进窄列。

## 合并显示的边界

同一容器内，只有物品类型、配发、校准、登记、保留随身状态全部相同的物品才合并。来源 ID 和实际数量仍保留在存档中。取放计划逐一指向真实批次，成功后统一记录撤销快照。

容量继续使用核心规则计算，包括堆叠和装备占格；图块数量不等于已用格数。野外按实际来源批次显示，拾取和放下继续经过场景费用及巡逻判断。同类物资对照表也保留逐批操作。
