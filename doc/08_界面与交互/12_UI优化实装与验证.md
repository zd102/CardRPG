# UI 优化实装与验证

本轮依据上一轮 23 张实际界面的评审落实修改。继续使用纸张、木刻和深绿色视觉语言，重点调整信息组织、预测口径与操作位置。首次游玩的关键说明直接可见；熟练操作使用固定工具栏、快捷操作和按页面记忆的密度。

可直接打开[新版程序](../../artifacts/Expedition-UI-20261016-Refined/CardRPG-Expedition.exe)或[前后对照画廊](../../artifacts/Expedition-UI-20261016-Refined/preview/index.html)。画廊提供原 23 个画面的同名对照及 10 张补充画面；验证记录保存在发布目录的 `validation.json` 与 `validation/`。

| 场景 | 本轮实际行为 |
| --- | --- |
| 背包与仓库 | 随身／仓库／所选物品三栏；当前容量保持真实值，取放后的容量、重量和压力放在详情栏。标准字号 1280×800 下至少完整显示 8 行仓库物品。 |
| 高频物资操作 | 搜索、分类、排序和视图入口固定；批量选择不增加工具栏高度；隐藏选中项、保护、数量、拖拽、右键与撤销保留。固定详情栏替代会挡住其他物品的自动浮层。 |
| 同类物资对照 | 汇总数量与具体批次区分；固定列标题；展开批次仍带物品名与保留标记。同类对照仍由玩家主动切换，避免把配发、校准、登记与保留状态误当成可合并实物。 |
| 拾取 | 同屏呈现随身清单与本地搜获；直接展示用途、拿取后容量和重量；按钮显示免费或压力消耗。 |
| 满包取舍 | 候选物品带图形、任务／保留标记、腾出格数、重量和后续拿取预测。放下与拿取仍分步执行，每一步重新检查巡逻。 |
| 出发整备 | 区分部署起点和任务目的地；显示穿戴、生命、卡组、起始工具代表卡、补给、已用格位与空余格位；预设靠近装备操作。 |
| 战斗 | 底部工作区限制最大宽度；行动点与区域压力分开命名。当前直接结束和出牌后再结束分别预测，均通过规则引擎连续执行；致命牌不会虚构下一次敌人行动。选牌时结束按钮明确写“按当前状态结束”。 |
| 长手牌 | 7／10 张手牌保留阅读宽度并横向滚动；键盘聚焦自动显示目标卡；手牌显示顺序与真实牌堆顺序分离。 |
| 改装与背包制作 | 改装明确只替换一张牌，展示伤害／护盾变化及拥有、消耗、剩余材料；背包容量变化不重复堆叠，已穿戴状态不再出现重复穿戴按钮。 |
| 场景、事件、任务与地图 | 热点缩短名称并区分形状；选项整块显示选中状态，补给使用独立图形；任务下一步置前；地图明确目的地、下一站和真实压力消耗。 |
| 结算与阅读 | 修复奖励名称逐字竖排；可交付时提供直接返回交付入口；列表行内部位置跟随字号缩放。各页面独立记忆信息密度。 |

验证覆盖核心规则测试、整章自动交互、真实渲染、1024／1100／1280／1600 宽度、720 高度、100%／125%／150% 字号、扩展文本、预览不改状态、取消、保留标记、拖拽、撤销、保存失败回退与模拟手柄输入。所有过程使用无头模式或未激活的隔离桌面，没有打开前台窗口。

测试只能证明这些流程和布局约束成立。真实玩家的理解速度与长期操作效率仍需实际试玩评价；本轮没有将自动化结果当成人类可用性测试结论。
