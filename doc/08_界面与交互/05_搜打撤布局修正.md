# 搜打撤布局修正

2026-10-14。针对首轮重组仍存在的排版问题，重新组织第一章管理界面。重点是把穿戴、携带与存储放进同一操作空间，并缩小导航和说明对主体区域的占用。

## 参考与取舍

参考《三角洲行动》[官方 Operations 入门指南](https://deltaforce.garena.com/en/news/system/RMDWVM)及其[仓库配装实机示例](https://web.df.garena.com/03_news/news_banner/SMP/202602_NewToOperations/2.png)。指南明确区分 Loadout 与 Storage；示例让装备、容器和物品同时可见。这里借鉴其空间组织与操作关系，不引入枪械配件、保险箱或实时射击规则，也没有复制其美术资源。

首轮的问题不只是按钮样式：左侧全局导航、顶部装备摘要和分类连续占用空间；仓库的大物件块使低分辨率退化成单列；固定的大段底部详情又压低容器高度。先前回归主要验证可操作与边界，不能据此判断视觉布局合理。

## 已调整的结构

| 页面 | 当前结构 | 解决的问题 |
| --- | --- | --- |
| 装备仓库默认页 | 顶部统一导航；左穿戴、中随身、右仓库／地面；底部窄操作条 | 取放时同时看到来源、目的地、当前穿戴和负重 |
| 装备比较 | 左穿戴、中候选、右供牌变化；底部固定换装操作 | 保留上下文，避免重复四部位横排和大段说明挤压选择区 |
| 行前整备 | 左穿戴、中部署地图、右清单；最终状态与部署按钮常显 | 目的地、携带量、负重和返还预留在出发前一起核对 |
| 战斗 | 压缩顶部菜单与引导；敌人向上扩展；资源、手牌、结束回合位于底部 | 减少装饰框与多行菜单，扩大敌人与公开意图的可见空间 |
| 工坊／任务／地图 | 共享顶部导航，内容按任务分区 | 去掉重复侧栏，归还横向阅读空间 |

库存使用 `ChapterSlotGrid` 计算格位；物件按真实堆叠量和占格显示，双格物连续排列，空位有背景格。分类筛选时不把未显示物件伪装成可用空位，容量标题仍反映真实库存。点击选择后在底条单件／整批取放，Shift+Enter 对当前批次执行整批操作；放弃、部分拾取仍走确认。此轮不包含拖拽、旋转或手动格位摆放。

操作面板使用平面浅色与细分隔；原有木刻场景、物品插画、地图和卡牌仍保留。阅读字号可调整，固定导航和物件名使用紧凑字号；它不等价于整个界面的 DPI 放大。

## 验证标准

- 库存容器至少显示三列；按实际格数对账，物件不重叠且不超出横向边界。
- 物资区高度至少占窗口 55%，底部操作条不超过 150 像素。
- 四个穿戴槽位均有足够名称宽度，在物资页无需滚动即可见。
- 1100×760、1280×800、1600×900 与 100%／125%／150% 阅读字号检查；已有确认、取消、焦点返回、保存失败回滚继续验证。
- 编译与规则测试之外，独立导出包还要完成无头交互和隔离桌面的真实渲染检查，不打开前台窗口。

实际结果、导出包校验值和截图见[验证留档](../media/ui-extraction-20261014/README.md)。后台验证不代表已完成真人可用性测试，最终视觉是否符合预期仍可直接通过这些实机图评估。
