# 第一章：余火铸造区

> 完整章节设计提案，2026-10-12。面向内容评审与后续实现，尚未落地、尚未经试玩验证。以下规则和数值是本章建议基线，不修改当前 Demo 的运行规则。

第一章围绕“把维持据点的设备带回家”展开。采用 **4 个分区、20 个探索地点、24 件装备、40 种卡牌、18 种敌人、7 项主线与 6 项支线**。目标体验为首次游玩的玩家完成主线、约 4 项支线、尝试至少两种构筑并进行 3～5 次制作或改装，约用 5 小时。

内容预算按约 9 次远征组织，不要求玩家必须出征 9 次。熟练玩家合并目标、跳过支线后，主线可能在 3～3.5 小时完成；不能用重复刷材料或强制撤离把流程拉长。

## 2. 世界、人物与冲突

旧文明把术式刻入金属，让武器、建筑与机械共用一种能量工艺。灾变破坏了炉心网络，城市分裂为仍能维持生活的灯区与危险的灰区。玩家所在的“余火站”依靠一座老化炉心，保护数十名居民。

玩家是能够使用并校准旧式装备的远征者。第一章的直接目标是找回稳压装置，让余火站安全度过即将到来的灰潮。灰潮是章节背景，不设置现实时间倒计时，也不因反复配装而扣减居民生存时间。

| 人物 | 在流程中的职责 | 通过行动呈现的关系 |
| --- | --- | --- |
| 工匠岑砧 | 装备制作、改装教学 | 先借给玩家工具，再逐步承认玩家自己的设计 |
| 医师阿苇 | 免费基础补给、净水任务 | 带回滤芯后，诊所亮起灯并恢复清洁供水 |
| 调度员洛舟 | 路线、货站、撤离情报 | 修复前进站后改变出发地点，减少重复赶路 |
| 旧区看守伊禾 | 铸造区避难所联系人 | 揭示中央稳压器仍在保护另一群幸存者 |

四名人物共用据点或少量固定场景，不扩展成同伴战斗系统。每次回营新增对话控制在 1～2 组，每组约 30～60 秒，可跳过并回看摘要。

## 3. 章节推进

### 第一段：学会带东西回来

外环货场承担基础战斗、搜索中断与首次撤离。玩家带回封装继电器，看到据点第一盏工作灯恢复。之后开启工坊，获得第一件手部装备，体验“防御也能用于攻击”。

### 第二段：开始带着目标出门

居住与水务区提供另一种武器、魔法防具和可追踪的材料。玩家决定先修水泵、寻找居民记录，还是挑战钟楼精英。第二套基础构筑在此阶段能够成立，不需要稀有掉落。

### 第三段：装备与路线相互影响

铸造与供能区提供蓄能武器、改装和首领。玩家可以切断警报降低支援，也可以自愿拦截高价值运货目标。找到稳压器底座后，是否继续挑战铸炉守卫由状态和收获决定。

### 第四段：把任务做完整

中枢档案揭示：直接搬走中央稳压器，会让旧区避难所失去保护。玩家有一条始终可完成的主线路径——收集旁路桥接件、分流供能；也可以完成支线找到备用炉芯，让旧区获得独立供电。

两条路径都能救回据点，差别体现在准备路线、最终战设施和结尾状态。没有只能靠前期隐藏选择才能达成的“正确结局”。最终击败中枢守卫后，还需带着装置前往撤离点；首领死亡不会自动结算。

## 4. 内容规模与学习顺序

| 首次出现阶段 | 新内容 | 本段只要求理解的核心问题 |
| --- | --- | --- |
| 0～30 分钟 | 初始铁锤、护甲、公开敌人意图、入口撤离 | 攻击还是防御；拿到任务物后什么时候回家 |
| 30～65 分钟 | 手部位置、盾压、工坊、第一次改装 | 护盾留着承伤，还是消耗后换伤害 |
| 65～125 分钟 | 连携武器、蓄能防具、前进站 | 先后顺序如何改变牌的价值；怎样缩短返程 |
| 125～195 分钟 | 进阶武器、饰物位置、精英与首领 | 当前组合是否值得深入；换装会失去哪些牌 |
| 195～260 分钟 | 混合构筑、中枢路线、备用炉芯支线 | 为目标准备装备与退路；是否增加一次冒险 |
| 260～300 分钟 | 供能方案、最终战、携货撤离、尾声 | 用已经掌握的机制完成一段完整远征 |

这些时间是设计预算；实际解锁依据任务，不依据游玩时钟。第一章只有护盾转换、攻击连携、魔法蓄能三个主要构筑概念，后期混搭使用同一组规则。

## 5. 持久性与叙事解释

装备记录着完整操作术式，卡牌表示此刻能够执行的动作。当地能量产生临时共鸣，离开灰区即失效。据点能够维护已登记装备；紧急回收能保护已校准的随身装备，但不能保障新发现的实物。

| 对象 | 成功撤离 | 战败 |
| --- | --- | --- |
| 已登记装备、已掌握配方、已购改装 | 永久保留 | 永久保留 |
| 本次拾取装备、材料、实体任务道具 | 入库；满足条件后可交付 | 丢失；关键道具可在原任务来源重新取得 |
| 已读情报、地图、已揭示的装备来源 | 保留 | 保留，但“看见”不等于获得配方或实物 |
| 临时共鸣、区域内一次性补给 | 结束时清除 | 清除 |
| 已完成的永久路线修复、已交付任务 | 保留 | 保留，不再次收费 |
| 普通搜索、当次敌人、巡逻和临时设施分配 | 下次远征刷新 | 下次远征刷新 |

永久路线修复是显式的世界进度例外，按钮需标明“永久修复”。普通临时供电不能冒充永久解锁。最终任务要求把稳压装置带回，战败不能凭读过结局情报完成章节。

## 6. 本章对现有 Demo 的建议变更

| 当前 Demo | 第一章建议 | 影响 |
| --- | --- | --- |
| 固定六地点、五件装备、八种牌 | 20 地点、24 件装备、40 种牌 | 新增目录与任务驱动内容；现有场景不能直接等同全部章节 |
| 武器、固定身体、可选护腕 | 武器与身体必备，手部与饰物分阶段开放且可卸下 | 装备全部供牌继续成立；卡组规模 8／10／12 张 |
| 工坊可调用全部绑定装备 | 出发带两件备用，途中只能使用随身或新获得装备 | 让出发选择有意义，需要新增备用清单 |
| 威胁只提高攻击 | 机会变化、巡逻预警与有限戒备 | 压力规则见区域文档；不叠加旧版攻击增量 |
| 撤退直接回入口 | 承受本轮意图后退回进入地点，接着自行撤离 | 修复利用撤退跳过返程的问题 |
| 材料只有累计 | 六材料、确定性制作、一个改装位 | 不引入随机重铸与维修费 |
| 护盾反击伤害随护盾直接增长 | 盾压消耗最多 8 护盾；保留明确上限 | 属于新牌定义，不能直接覆盖旧存档里的牌 |

实现时需新增内容版本与存档迁移，不能将本文卡牌 ID 混入旧目录后宣称兼容。完整章节需要任务、物品实例、区域调度和敌人意图系统，远超单纯扩充文本。

## 7. 章节完成标准

玩家通过自己的装备与路线选择带回稳压装置，余火站恢复稳定供能，旧区避难所根据方案获得分流或独立供电。结尾展示本章找到的装备、使用过的组合与仍可追踪的来源，并允许回访；收集全套装备不是主线通关条件。

内容验收必须证明第一次撤离、第一次组合成立、第一次主动收手和一次准备充分的深入挑战都真实发生。具体时长与数值结论须经过[试玩验证](06_节奏验证与实施.md)，本设计不将估算当作实测结果。
