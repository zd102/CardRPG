## 装备结构

**有哪些装备部位？每个部位允许多少件装备？**

已确认如下；护符可用槽位随游玩进度由 1 个解锁至最多 4 个。

| 部位 | 容量与占用规则 | 卡牌贡献 |
| --- | --- | --- |
| 武器 | 支持一件双手武器，或两件单手武器；双手武器占用双手，不能同时再穿戴单手武器 | 每件实际穿戴武器按自身配置提供 x 张 |
| 头盔 | 1 件 | 提供对应的 x 张 |
| 身体护甲 | 1 件 | 提供对应的 x 张 |
| 手套 | 1 件 | 提供对应的 x 张 |
| 鞋子 | 1 件 | 提供对应的 x 张 |
| 戒指 | 2 件 | 每件分别提供对应的 x 张 |
| 护符 | 1～4 件，受当前已解锁槽位数限制 | 每件分别提供对应的 x 张 |

双手武器即使占用双手也只是一件装备，其卡牌清单只计一次；两件单手武器分别计入。具体 x 不预设为相同，也不假定双手武器供牌量等于两件单手武器之和。

只穿戴一件单手武器的占位细节、主副手差异、同名戒指／护符可否同时穿戴、是否存在其他武器副手类别：待填写。未穿戴武器时仍按既有规则加入默认卡牌。
