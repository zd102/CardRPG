# 奖励、撤离与长期进度

> 2026-10-12。[返回概览](../00_游戏概览.md)

本文下述数量和自动领取为旧六地点原型行为。2026-10-13 新增[背包与仓库设计](02_背包仓库与遗留物.md)及[消耗品设计](03_消耗品与补给.md)：搜索／胜利先把实物留在来源，确认拾取才占用随身容量；只有实际携带物随撤离保住，仓满余物留在合法随身格。未拾取物同次可返回，远征结束重置。背包、地面库存、仓储和 U01 已接入外环；完整章节的收益预算仍需按实际装包重新核算。

## 三种归属

- 绑定装备与仓库材料：在据点保留，战败不会没收。
- 当前战利品：本局发现的装备和材料，撤离前未入库；装备即使穿戴也仍会因战败丢失。
- 临时祝福：本次远征的变化，撤离和失败都会清除。

情报一经调查永久保存。首领死亡不是远征结束，玩家仍需主动前往出口；首领奖励也没有自动保险。

## 当前奖励

运输队给破甲锤与 3 材料；巡逻单独遭遇给 3 材料；首领给护腕与 8 材料。运输队合并巡逻按该场运输队遭遇发一次 3 材料，不额外叠加巡逻奖励，界面不承诺按敌人数发奖。

废料场一次搜索给 3 材料和 1 补给。保险箱完成后给 5 材料及破甲锤/护腕之一。随机状态进入存档，正常读档不能重抽。

入口免费撤离；货运站需先恢复电源，然后也免费撤离。撤离将所有物品入库，未收藏装备成为绑定收藏，重复装备每件回收为 3 材料。结算阶段不能再次撤离或领取。

## 失败与撤退

战败丢失本局所有装备和材料，保留已有收藏、仓库和情报。没有维修费、跑尸或死亡掉落物。回据点满血后可重新出征。

战斗内撤退需要撑过公开的敌方攻击，成功回入口并损失最多 3 材料，仍可选择撤离或再次深入；本场不发奖励。战败则不能把战斗撤退当成保险通道。

## 随机成长

工坊装置随机提供三种祝福中的两种，玩家选择一个。本局只能选一次：攻击伤害 +2、每回合护盾 +3、每回合额外魔法 +1。未来可增加多个祝福槽和相互作用，当前没有祝福叠加。

Demo 材料只累计，没有正式消费；无装备耐久、负重、保险容器、商店或制作树。正式版优先增加定向装备来源和材料出口，避免靠无限重复低风险地点支撑经济。
