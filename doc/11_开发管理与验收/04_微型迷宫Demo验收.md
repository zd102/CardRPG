# 微型迷宫 Demo 验收

> 2026-10-09 · Godot 4.7.2 .NET / .NET SDK 10.0.401 · Windows x64

「灰烬回廊」已完成首个可玩版本。本次验证探索、遮挡与空间回路；移动方式、视距、地图规模及物品数量为原型参数，不将相关设计草案整体改为正式定案。

入口与操作见[项目 README](../../README.md)。本机成品位于 `artifacts/MicroMaze/`，程序名 `CardRPG-MicroMaze.exe`；交付整个文件夹。

## 可玩流程

入口庭院 → 推开北侧木门 → L 形北廊 → 大厅铜钥匙 → 深侧捷径与可选旧银币 → 铜锁门 → 祠堂出口。捷径和银币均为可选探索，出口需要靠近后主动交互。

玩家可开关木门；门洞被角色占用时不能关门。捷径首次仅允许从东侧打开，解锁后可从两侧使用。物件必须处于当前视野和交互距离内才能交互；拾取后的物品不会重复领取。

## 实现边界

| 内容 | 本次实现 |
| --- | --- |
| 地图 | 35 × 25 固定布局；JSON 是地形与物件位置的唯一来源 |
| 移动 | 连续坐标与任意方向移动，行进距离不取整；斜向等速，墙面滑动，圆形角色扫掠检测防止穿墙与切角；键盘保留 WASD / 方向键 |
| 鼠标移动 | 保留已探索地面的精确点击坐标；空旷区域直线到达，障碍附近平滑绕行，无格心吸附；圆形落点标记、右键停止、键盘接管 |
| 鼠标交互 | 点击可见物件，走到交互距离后对该物件执行操作；沿途其他物件不自动触发 |
| 视野 | 半径 6.5 格；墙和关闭的门遮挡，保守处理对角接缝 |
| 记忆 | 仅保留已见地形与上次观察的门状态；视野外物品不显示 |
| 栅栏 | 可透视、不可通行；观察不等于到达或激活 |
| HUD | 取消底部与右侧大面板，场景铺满窗口、镜头居中；左上显示区域与目标，右上提供地图、暂停、帮助小图标，已取得的物品按需显示 |
| 场景指引 | 起步提示移动后消失；悬停或靠近物件显示操作文字，可按 E 的目标附快捷键；提示不拦截点击，交互反馈自动淡出 |
| 菜单 | 地图、暂停、操作指引与重开确认按需打开；全部菜单提供鼠标入口，包括取消重开 |
| 完成 | 出口结算显示本次时间和实际取得的纪念品；支持重新探索 |
| 架构 | 纯 C# 规则项目与 Godot 表现项目分离；TileMapLayer 呈现地形 |

像素图块和角色由项目代码绘制，无外部素材；中文使用系统字体。当前为 Windows 原型，其他系统的字体可用性与导出尚未验收。

图形验证使用本机 Intel UHD Graphics 770、ANGLE / Direct3D 11。上述结果不代表已在无开发环境的另一台设备验证，也不构成帧率或正式性能预算结论。

`--verify-demo` 验证键盘回归和完整流程；`--verify-mouse` 只通过鼠标事件驱动实际 GUI、输入和物理更新，不直接调用移动、交互或重开方法。两者均需显式启用，正常游玩不启用验收脚本。可另加 `--capture-dir=<绝对路径>` 保存验收画面；鼠标验收使用加速模拟缩短等待时间。

鼠标寻路只读取已探索地形与最近观察到的门状态。隐藏物件不提供悬停提示，也不会因鼠标点击而远程交互；关闭的门仍需主动点击打开。空旷区域直接连接实际位置与精确落点；受阻时通过八邻域 A* 找到绕行通道，再以角色体积检测消除多余转折。实际移动方向和终点均为连续坐标，不强制经过每个格心。路径简化、途中校验与角色移动共享圆形扫掠检测，防止切过墙角；路径被关闭的门阻断时停止并提示。

验证完成后，已按明确路径清理本次 `.godot`、C# `bin/obj` 和重复验证截图；保留 `artifacts/MicroMaze/` 可玩包与 `doc/media/micro-maze.png` 文档预览。源码启动脚本会重新生成所需缓存。
