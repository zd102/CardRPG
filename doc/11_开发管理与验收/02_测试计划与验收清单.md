## 已确认核心规则的检查

以下为待执行的设计验收，尚未验证实现。

| 条件／操作 | 预期 |
| --- | --- |
| 创建角色 | 无职业选择 |
| 属性不足，随后加点满足需求 | 对应装备属性门槛由不满足变为满足 |
| 穿戴多个合法装备 | 卡组完整累加各装备提供的卡牌与张数 |
| 两件装备提供相同卡牌 | 保留全部副本，移除一个来源不影响另一个来源 |
| 完全不穿装备 | 加入非空默认卡牌 |
| 仅穿防具、不穿武器 | 防具卡牌之外仍加入默认卡牌 |
| 穿戴武器／卸下最后一件武器 | 构筑结果分别移除／加入默认来源卡牌 |

属性降低、战斗中换装、存档恢复等案例须先确认相应细节规则。
