# UI 重组截图与验证证据

> 首轮历史留档。用户反馈后已再次修正布局，当前导出包见[搜打撤布局截图](../ui-extraction-20261014/README.md)。这里的源码校验值对应首轮快照，不代表后续代码。

本目录留存第一章 UI 重组后的实际 Godot 渲染截图、总览和源码校验信息。截图由 `scripts/verify-ui.ps1` 在未激活的 Windows 隔离桌面获取；没有打开前台窗口，也没有读取或写入玩家存档与偏好设置。

最终构建 0 警告、0 错误，77 项核心测试通过；无头与真实渲染回归均以退出码 0 完成。生成 116 张截图，本目录保留 17 张原图、10 张总览及完整清单。

完整实现对应关系见 [22 组建议实施记录](../../08_界面与交互/04_UI重组实施与验收.md)。原始图像与校验值以 `manifest.json` 为准，`source-sha256.json` 记录受检源码，`render.txt` 记录实际渲染回归结果。

`contact-*.jpg` 是全量截图的缩略总览；用于检查覆盖和整体排版，不能替代关键文字的原尺寸检查。仅重点页面保留原始 PNG，其余截图保留总览与原图 SHA-256，可重新执行后台脚本生成。

“150”表示规则与说明采用 24 像素阅读字号，并非操作系统 DPI 或全界面放大。保存失败截图来自验证专用开关，玩家磁盘与存档没有受到故障注入。截图中的滚动位置、选中项与提示取决于自动输入步骤；视口裁切长列表本身不等于控件溢出。
