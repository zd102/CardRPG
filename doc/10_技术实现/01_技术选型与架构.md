# 技术架构

> 当前实现，2026-10-12。[返回概览](../00_游戏概览.md)

Godot 4.7.2 .NET + C#，.NET SDK 10.0.401。Windows 使用 ANGLE / Direct3D 11 兼容渲染。

| 文件 | 职责 |
| --- | --- |
| src/CardRPG.Core/ChapterContent.cs | 外环牌、装备、地点、配方与任务目录 |
| src/CardRPG.Core/ChapterState.cs | 可序列化章节状态与暂停战斗 |
| src/CardRPG.Core/ChapterSession*.cs | 合法命令、任务、战斗、制作与存档检查 |
| game/Scripts/ChapterGame*.cs | 页面、输入、自动保存 |
| game/Scripts/ChapterScene.cs | 场景、地图及据点变化 |
| game/Scripts/ChapterVerification.cs | 隔离存档的真实输入验证 |
| game/Scenes/Chapter.tscn | 默认游戏入口 |
| tests/CardRPG.Core.Tests/ChapterTests.cs | 章节流程与失败恢复测试 |

核心库不依赖 Godot。界面调用命令，成功后保存与刷新；浏览不推进。阶段为据点、探索、战斗、成功撤离与失败；台架为隔离战斗实例。旧 Expedition 类、场景和测试保留回归，不是默认游戏入口。

内容暂以内置 C# 目录维护，不声称支持 JSON 配表热更。存档使用 JSON，记录完整远征状态。后续内容增长时再分离定义和实例、增加配置校验与版本迁移。

当前没有碰撞、寻路、空间视野或实时接触组件。世界变化只发生在明确命令内，战斗不调用区域推进。规则测试可独立验证这些边界。

集成验证通过实际 GUI 鼠标事件点击按钮，并通过键盘 Enter 发起下一次远征；不能用仅直接调用规则方法的测试代替输入验证。
