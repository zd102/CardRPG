# 技术架构

> 当前实现，2026-10-12。[返回概览](../00_游戏概览.md)

Godot 4.7.2 .NET + C#，.NET SDK 10.0.401。Windows 使用 ANGLE / Direct3D 11 兼容渲染。

| 文件 | 职责 |
| --- | --- |
| src/CardRPG.Core/ExpeditionContent.cs | 牌、装备、地点与连接的原型目录 |
| src/CardRPG.Core/ExpeditionSession.cs | 状态、合法操作、行动步、接战、牌区、奖励与序列化 |
| game/Scripts/ExpeditionDemo.cs | 页面、输入、自动保存、数据展示 |
| game/Scripts/IndustrialBackdrop.cs | 可缩放的代码绘图 |
| game/Scripts/ExpeditionVerification.cs | 不污染存档的真实输入集成验证 |
| game/Scenes/Expedition.tscn | 唯一游戏入口 |
| tests/CardRPG.Core.Tests/ExpeditionTests.cs | 无引擎规则测试 |

核心库不依赖 Godot。界面调用命令方法，成功后保存与刷新；浏览不调用推进命令。状态阶段为据点、探索、战斗、祝福选择、成功撤离和失败。

内容暂以内置 C# 目录维护，不声称支持 JSON 配表热更。存档使用 JSON，记录完整远征状态。后续内容增长时再分离定义和实例、增加配置校验与版本迁移。

当前没有碰撞、寻路、空间视野或实时接触组件。世界变化只发生在明确命令内，战斗不调用区域推进。规则测试可独立验证这些边界。

集成验证通过实际 GUI 鼠标事件点击按钮，并通过键盘 Enter 发起下一次远征；不能用仅直接调用规则方法的测试代替输入验证。
