# 灰烬远征 · 游戏设计概览

> 当前基线：2026-10-12。装备驱动卡牌 RPG，结合肉鸽远征、定向装备获取与搜打撤。文档只维护当前方向。

玩家从据点选择装备组成卡组，在按行动推进的区域内调查、搜索、改变敌人条件、进行卡牌战斗，最终主动撤离。装备提供长期追求，临时祝福提供每次变化，未撤离战利品提供风险。

**主循环：据点整备 → 区域行动 → 装备与临时构筑成长 → 挑战或撤离 → 入库并再次出征。**

## 已落地的第一章外环

Windows 本地单人，Godot 4.7.2 .NET + C#。默认入口现为第一章外环：7 地点、8 装备、13 种牌、2 主线、4 完整支线及台架试用，包含维修偶、荧光暗室、列车包裹、制作改装与两种出发／撤离位置。通过当前场景按钮操作，地图只读；阅读和战斗思考不推进区域压力。

实物需撤离入库，救援、修复与交付永久保留。Q02 开放手部、制作与改装，最多两件备用；第一章独立存档，不覆盖旧 Demo。后续分区尚待实现，详见[外环实现与验收](13_第一章_余火铸造区/08_外环实现与验收.md)。下表仍描述六地点的原型规则文档不覆盖章节实现记录。
