# 灰烬远征 · 游戏设计概览

> 当前基线：2026-10-12。装备驱动卡牌 RPG，结合肉鸽远征、定向装备获取与搜打撤。文档只维护当前方向。

玩家从据点选择装备组成卡组，在按行动推进的区域内调查、搜索、改变敌人条件、进行卡牌战斗，最终主动撤离。装备提供长期追求，临时祝福提供每次变化，未撤离战利品提供风险。

**主循环：据点整备 → 区域行动 → 装备与临时构筑成长 → 挑战或撤离 → 入库并再次出征。**

## 已落地的 Demo

Windows 本地单人，Godot 4.7.2 .NET + C#。一个区域、六个地点、两种起始武器、五件装备、八种牌、三种临时祝福、两种撤离位置。玩家通过点击地点与行动按钮操作；阅读、思考、浏览和卡牌战斗不推进场外时间。

地图固定；祝福选项和保险箱装备随机，随机状态随完整存档保存。战利品只有撤离后才入库。基础装备绑定，战败丢失本局发现的装备和材料。Demo 没有属性加点、完整穿戴槽位、随机词缀、装备制作、负重或多人功能，不把这些长期设计写成已实现。
