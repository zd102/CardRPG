## 1. 建设循环与范围

**看见一处尚未恢复的用途 → 选择想建的项目 → 追踪明确来源 → 远征带回 → 确认安装 → 使用新设施，并在家中看见变化。**

建设分为任务设施、可选工程、仓库扩建和个人布置。任务设施承接章节推进；八项工程提供试验、筹划或陈设用途；仓库独立扩容三次；个人布置免费切换，不再派生其他等级树。

| 类型 | 取得方式 | 玩家选择 | 第一章边界 |
| --- | --- | --- | --- |
| 任务设施 | 完成原主线／支线，交付对应任务物一次 | 先处理哪个目标、何时带回并交付 | 基础功能的开放条件保持原有任务定义 |
| 可选工程 | 满足条件后，从仓库支付一笔固定材料 | 先做装备还是先建设施，选择追踪哪个项目 | 8 项，一项只建一次；没有建设失败或施工等待 |
| 仓库扩建 | 满足任务前提，从安全库存支付材料 | 为收藏与储备扩容，还是先做背包／药品 | 48→72→96→128 格；不增加随身容量 |
| 个人布置 | 工程或剧情开放摆位与外观 | 人台装备、投影片段、灯罩、桌面纪念物 | 固定插槽，免费更换，不提供隐藏属性 |

第一章没有基地等级、工人数量、食物消耗、维护税、随机袭击或建筑耐久。炉心供能是章节目标与场景状态，不另加实时电力分配。基地不会随现实时间损坏，也不通过居民苦难催促玩家上线。

## 2. 永远可用的基础服务

免费基础恢复和补给、公共起始装备、入库、地图与已知来源、普通装备比较、手动配装和合法出发始终可用。它们不需要付建设费用。Q02 之后的制作、改装、原 X05 试用也不再收费解锁一次。

P01～P08 不增加人物生命、行动、每回合抽牌、备用数量、装备部位、永久掉落倍率或死亡保物比例。W01～W03 只增加仓库容量；背包容量来自实际穿戴背包。战斗成长继续来自装备和合法改装。

因此，即使八项工程一项也没建，玩家仍能完成全部主线，也能获得已有支线承诺的维修偶、电台、植物和守夜机。

这些项目不是八级连锁。P01～P04 可以任意顺序建设，P05～P08 只依赖表中的任务，不依赖前面的工程。建设无限并存，不另外加入占地、供能槽位或工人人数限制；玩家的短期取舍来自共享材料和远征目标。

P03/P05～P08 的主要收益是生活和收藏，应在项目卡上直说。偏战术玩家可以跳过。若试玩中 P01/P02/P04 被普遍视为“必须先付费的基础工具”，优先下放其中的基本功能，让工程保留进阶试验和场景表现，不抬高装备成本来强迫取舍。

### 配装与试验的边界

保存人台方案不会登记未带回的装备，也不复制任务物。应用时验证持有、部位和已购改装，失败项逐一提示；事务完成前保留原配装。

P02 只在据点开启，用已登记装备与已购买改装。固定起手从实际牌包合法抽取并保存，不能凭空塞入牌副本。敌人模板仅含已实际见过的普通敌人意图，首领及未见阶段不在首版支持范围内。模拟不提供掉落、材料、战斗胜利、任务进度或永久研究奖励。

原 X05 教学可借用 G26；它是独立教学入口，原定的 S10 首阶段完成条件仍然有效。普通靶台不能伪造 X05 完成。退出任一试用必须恢复真实生命、牌区、资源、随机状态与物品归属，借品不能带走。

P04 的步数是已知下界：移动边数＋明确的交互步数。若规划包含噪声搜索，旁边单列巡逻风险；不能把模拟出来的路线写成已经开启的捷径。

## 6. 建设操作与撤销

工程状态为：条件未满足 → 可预览 → 材料齐备 → 已建成。可预览与材料齐备由任务和仓库动态计算，已建成单独持久保存；追踪仅是 UI 状态，不扣料、不锁材料。

流程：打开项目 → 看效果及前后对照 → 显示仓库与安全随身材料余量及扣料来源 → 确认建造 → 原子扣料、写入完成与事件 → 保存成功 → 播放可跳过的 2～4 秒变化。首版没有半成品、施工队列、现实等待或花钱加速。

确认页示例：

> 建造配装人台  
> 废钢 4 → 2；精密弹簧 2 → 1。立即完成。  
> 可保存两套配装；不增加穿戴位置或备用容量。  
> 建成后永久保留，材料不返还。你可随时免费调整展示和已存方案。

关闭预览与取消确认无变化。建成后没有拆除退款，避免反复退款与存档刷新套利；所有外观、摆位、展示选择都可免费恢复默认。一次建造的收费后果需在按钮旁明确展示，播放动画不再重复确认。

已有藏品放入陈设位只保存引用，物品仍可正常穿戴和使用；唯一实物不因此消失。任务物、借用品、未撤离装备不能作为可消费的建筑材料。

## 7. 玩家选择的具体例子

Q02 后玩家拿着废钢和弹簧，准备去泵站。可以把废钢做成另一把武器，也可以先造人台，保存铁锤护盾与短杖两套配置。若更关心高费群攻有没有用，可先做靶台，用两名已见敌人的意图练习行动点分配；基础教学始终仍可免费进入。

第三趟带回滤芯，诊所直接出现流水。此时长桌已经可预览，但玩家刚做完装备，暂时缺废钢。他把长桌作为可选追踪，第四趟仍去推进钟楼，不为基地改走一条强制刷料路线。之后顺路从模具仓带回废钢，再把走廊整理成聚餐位置。

玩家同时送回过居民包裹，长桌旁的人会穿着那件修补过的工作服。任务交付、建设摆位与环境对话组合成一个个人经历；不需要再增加一个“居民满意度 +5”的结算框。

## 8. 第一章之后的扩展位置

后续章可以扩展已有房间的功能分支，保留第一章建成的外观与收藏。优先方向是工坊的有限工艺研究、调度室的一次出征服务、生活区的跨区人物回响。

若要加入影响真实远征的基地能力，建议单独验证“每次选择一种支援”：例如提前显示一个已存在的巡逻条件，或在指定前进站使用一次运输。必须先确定一次性触发、费用、保物范围和与撤离风险的关系，再加入设计。此类效果不包含在本章八项工程，不默认与全部成长系统叠加。

组合笔记先做玩家记录，不把 P03 暗中变成永久技法研究树。将局内共鸣转为常驻改装，继续按[局外成长备选](../01_游戏定位/06_局外成长评估与备选设计.md)另行评估占位、强度与样本条件。

## 10. 数据与存档约束

建议新增 `BaseState`，内容版本单独升级；现有外环存档中的任务集合仍是已交付任务的依据。这里是数据需求，不表示字段已经存在。

| 数据 | 作用与约束 |
| --- | --- |
| `CompletedProjects` | 已建项目 ID 集合；唯一事务防重复扣料 |
| `TrackedProject` | 至多一个项目；条件不足也能追踪，不能自动接受任务 |
| `Layouts` / `Displays` | 各固定位置的摆位与收藏引用，加载时验证合法性 |
| `LoadoutPresets` | 两个人台方案，存装备、改装和备用引用；应用前重验 |
| `RoutePlans` | 两条已知地点序列、目标和出口；读取时重算可达性与步数 |
| `PersonalNotes` | 最多三条玩家笔记；纯文本，不解释成脚本或卡牌规则 |
| `BaseEventsSeen` | 场景演出是否已看／跳过；不决定物品是否已发放 |
