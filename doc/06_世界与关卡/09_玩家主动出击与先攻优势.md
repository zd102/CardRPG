# 玩家主动出击、构筑差异与先攻优势

> 状态：设计草案，待原型验证 ｜ 更新日期：2026-10-09 ｜ 实现状态：尚未接入 Demo

建议提供**统一主动出击操作，由当前装备供牌明确解锁开战技；出击结果决定首轮顺序，选用的能力决定一张首手准备牌，怪物状态决定可利用的开场机会**。探索中不抽手牌、不先结算伤害。伤害、防御和打断都通过进入战斗后的正常出牌完成，保留装备组成卡组及每回合抽 5 张的既有规则。

需要按构筑区分可用能力，但不按“攻击牌占比”“魔法牌超过一半”自动划分职业。玩家自由搭配装备，混合构筑可以获得多个候选能力；每次探索只装配一个开战技。所有合法构筑另有基础迎战，纯防御、辅助或暂时没有合适开战牌的玩家也能主动接敌。基础迎战只争取顺序，不授予准备牌或额外开场机会。

本方案增加此前未设计的首轮顺序优势与有限开场条款，调整 P-003／P-004 中“地图接敌不赋予先手”的草案；继续禁止地图免费伤害、额外完整回合和提前消耗不存在的探索手牌。卡牌具体数值、正式战斗形式及队伍人数仍待确认。

## 1. 构筑如何决定主动能力

### 读取明确授权，不推断整副牌的职业

开战技通过明确的配置关联“来源装备 → 该装备提供的卡牌 → 地图动作”。一张牌可以声明适用的开战动作与开场条款；并非所有攻击牌都自动成为地图技能，也不从“火”“箭”“突进”等名称猜测射程与移动能力。

玩家在非警戒时从当前构筑提供的候选中选一个开战技，并选定它对应的一张准备牌来源。混合构筑可以在刀剑突击、弓箭点射和术式引战之间选择，双持或重复卡不会叠加地图射程、释放次数或准备牌数量。进入警戒、开始出击、战斗、结算或返回保护后，不能换装备或更换装配的开战技；基础迎战始终作为无准备牌的备用操作。

| 构筑具备的内容 | 可用的地图动作 | 进入战斗时的构筑表达 |
| --- | --- | --- |
| 短距攻击牌，显式允许突击 | 短前摇攻击选定近处怪物 | 首手准备该来源的一张近战牌，可选择带突袭或打断条款的牌 |
| 弓弩直射牌，显式允许点射 | 站定瞄准可见目标 | 首手准备一张对应射击牌，射程与射线依地图配置 |
| 符合首回合费用的基础法术牌 | 较长前摇的术式引战 | 首手准备该法术，属性与效果在正常出牌时结算 |
| 格挡、护盾等明确允许迎战的牌 | 对近处怪物摆出迎战姿态 | 首手准备防御牌，适合截住追击或面对多怪 |
| 只有高费法术、复杂连锁牌，或无合适授权牌 | 基础迎战 | 可以争取行动顺序，但不凭空获得攻击牌或准备牌 |

纯辅助／防御牌不因为没有伤害就不能授权迎战。治疗、召唤、群体、随机目标、依赖弃牌区或复杂条件的牌，首轮不自动开放为远程开战动作；它们仍可正常存在于卡组。后续是否授权，需逐牌验证首回合合法性及探路、无消耗治疗等问题。

**无武器时仍只使用现有默认供牌规则。** 基础迎战是地图操作，不向卡组添加新卡；无武器默认牌中如有明确授权的能力，可以正常成为候选。穿武器但配置异常导致卡组为空，也不能借本系统自动补牌掩盖错误。

### 费用在战斗里支付

探索阶段没有随机手牌，也不运行行动点和魔法点回合。地图前摇只决定能否成功接战；来源卡不在地图上视为已使用，不触发抽牌、治疗、护盾、装备连锁或资源恢复。

有准备牌的能力，需在装配和释放时检查该牌在正常首回合是否可用：行动卡费用不高于首回合行动点预算，魔法卡费用不高于 `min(魔法点上限, M0 + 首回合恢复量)`，并满足无需特殊牌区的基础目标条件。这里沿用战间资源草案的 M0，正式数值未定。高费大招不能仅凭出现在卡组中获得远距离廉价引怪能力；不满足时说明原因，仍可用基础迎战。

该检查只决定能力是否可选，不预支或锁定战斗资源。入场后若敌方效果改变费用或资源，准备牌照常遵守新条件，可能暂时无法使用；不会自动减费、透支或返还“地图已支付”的费用，因为地图未扣费。

## 2. 玩家怎样执行出击

使用一个统一的主动出击按钮与可见目标选择。鼠标点击敌人只选择目标，明确点击出击按钮才施放；键盘也使用同一目标与释放判定。超出范围时显示原因，不自动穿过未知地形、追着怪物移动或绕过门去释放。

所有主动动作都要求目标已满足共同规则的可见观察窗口。近距动作要求无实体阻隔；远距动作与怪物使用相同的视线、射击通道及允许交战区规则。不能选中墙后、视距外、楼层外或独立挑战中的怪物，也不能对空地施放来扫描隐藏敌人。

| 能力原型 | 建议范围／前摇 | 地图表现与取舍 |
| --- | --- | --- |
| 基础迎战 | 1.2 格／0.35 秒 | 无准备牌；近距明确发起挑战，所有构筑可用 |
| 短距突击 | 1.2 格／0.35 秒 | 挥击准备，不附带位移；需要先安全接近 |
| 弓弩点射 | 4 格／0.8 秒 | 全程站定且保持射线；有距离便利，不能穿掩体 |
| 术式引战 | 3.5 格／1 秒 | 明显施法动作；准备对应基础法术，容易被近处追击打断 |
| 架势迎战 | 1.2 格／0.5 秒 | 准备防御牌；地图上不提前产生护盾 |

这些是原型调试值，不从卡牌伤害、稀有度或战斗属性“速度”直接换算。首轮不提供地图群攻、瞬移突进、持续弹体或远程治疗；一次主动动作只指定一个怪物。

按下出击后地图继续运行。怪物按实际视听线索发现动作、预警、追击或瞄准，不能因为玩家正在准备而停住。近距动作提供局部动作声，远程点射提供拉弓／武器声，术式提供更明显的声光；各自使用显式声音半径，传播规则沿用听觉系统。能直接看见动作来源者进入自己的预警，隔墙只能听到者先搜索，声音不自动拉人参战。

玩家可以用移动或取消中止前摇；失去目标可见性、射线、射程或合法交战区也会中止。中止后不扣战斗资源、不生成伤害或准备牌，已经引起的警戒保留。建议设置 0.5 秒再次出击间隔，期间仍可移动；只对实际开始的动作计间隔，无效点击不受罚。每次重新开始都需完整前摇，不能在掩体后蓄满再探头瞬发。

同一步敌人已完成合法接战时，不等待玩家剩余前摇。玩家尚未完成的动作取消，进入该敌人发起的战斗，不获得其准备牌或出击奖励。普通走近碰撞也仍有效，但不等于成功释放开战技。

## 3. 一次确定参战者与先攻归属

### 三类请求统一收集

在原有统一逻辑步中增加玩家完成请求：

`D = 合法接触怪物 ∪ 完整瞄准的远程怪物 ∪ 玩家成功出击的选定目标`

玩家远程命中的目标无需自己完成瞄准，也不必贴身，就会进入 `D`；这是一项被玩家明确攻击的直接参战资格，不是未完成预警的自动协战。同一目标同时符合多种请求只计一次。附近其他怪物继续按 P-003／P-004 的规则进入协战集合，不能从被攻击者向外递归拉人。

先用本步最新的门、移动、可见性和射线复核全部请求，再合并名单。成功出击的目标与其他直接触发者同等处理，全部保留；常规最多 4 只的目标仅限制补入协战者。精英／首领确认入口默认不接受这些普通主动动作，也不因玩家装配了开战技而额外授予准备牌。

在请求中额外区分：

- **P：玩家开战技完成。** 基础迎战也属于 P，但没有来源牌可准备。
- **E：敌人主动接战完成。** 包括完成预警后由怪物接近造成的接触，以及敌人完整远程瞄准；玩家走过去碰到站立怪物不算 E。
- **C：普通接触。** 用于参战名单，不单独授予玩家先攻。若敌我都在靠近且怪物已具备主动接战资格，记为 E，不能靠玩家持续按前进改写为玩家主动。

| 同一冻结步的有效请求 | 首轮顺序优势 | 准备牌 |
| --- | --- | --- |
| 有 P，无 E | 玩家出击角色先攻 | 装配能力有合法来源牌则准备 1 张 |
| 有 E，无 P | 一只直接发起的怪物先攻 | 无；未完成的玩家动作不能带入 |
| P 与 E 同一步均有效 | 正常顺序，视为交锋 | 玩家已完成有来源的能力仍准备 1 张，但没有顺序优势 |
| 只有 C，或明确挑战入口正常开战 | 正常顺序 | 无主动出击准备牌 |

先攻比较的是**有效动作完成**，不是谁先按键、谁先发现谁或谁的动画回调先执行。每个逻辑步都检查一次，较早完成就已经冻结地图；同一步统一视为交锋，不增加对帧率敏感的毫秒抢占。多个 E 同步成立时，按基础战斗速度、稳定实例序号选一只先攻者，不能让整个敌群全部获得提前行动。

### 提前正常回合，不新增完整回合

原型建议以“每个单位每轮一次正常回合，基础顺序按速度从高到低、同速按稳定序号”验证。先攻者的**第一个正常回合**移到第一轮队首，原位置移除；其余单位维持相对顺序，第二轮恢复基础顺序。队伍若后续采用，只提前执行主动出击的那个角色，不提前整队。

例如基础顺序为 `快怪 → 玩家 → 慢怪`，玩家先攻后第一轮变为 `玩家 → 快怪 → 慢怪`；第二轮恢复基础顺序。不会变成 `玩家 → 快怪 → 玩家 → 慢怪`。提前行动仍执行一次正常回合开始、资源恢复、抽牌、行动和结束弃牌。

正式战斗形式尚未确定，上述为可执行的原型假设。若以后采用时间轴，必须把优势映射为一次初始排序调整，并保留“没有多一轮恢复和抽牌”的约束。先攻不会降低敌方速度、眩晕全体、增加行动点、补满魔法点或默认提升伤害。

## 4. 如何让先攻与卡牌实际联动

### 一张准备牌占首回合的五张之一

玩家成功完成有来源的开战技时，在锁定装备后，从该来源选择一个真实卡牌副本：其余副本正常洗牌，再把这张牌放到抽牌区顶部。首个玩家回合照常抽 5 张，因此通常得到“准备牌 1 张＋其他牌 4 张”。牌组只有 3 张就最多抽到 3 张，不补造卡牌。

准备牌不在入场时额外加入手牌，不复制，不视为已经打出，也不自动减费。真正使用时按行动卡／魔法卡支付对应资源，使用后正常进入弃牌区；不用则在回合结束时一同弃掉，不永久保留。

同名牌按来源和实例区分，双持同名牌也只准备一个副本。成功释放之前不得先看随机首手再决定准备哪张；准备结果、其他牌的洗牌随机状态及消耗记录随遭遇保存，反复读档不能换牌或重复获得优势。首回合抽牌前若以后允许洗牌、移顶牌或弃牌等特殊效果，按显式效果处理，不额外补回被改变的准备牌。

### 怪物状态提供机会，卡牌负责兑现

只记录一个主动选定的主目标及一个开场机会；玩家需要在自己的首个正常回合中，实际打出带相应条款的卡牌才能兑现。它可以是准备牌，也可以是正常抽到的合法牌。没有匹配牌、资源不足、目标死亡或机会过期，就没有额外收益。

| 地图情形 | 可记录的机会 | 卡牌条款示例 | 限制 |
| --- | --- | --- | --- |
| 成功抢先出击；目标在本次动作前未警觉，释放时仍未完成预警 | 突袭 | 带“突袭”的单体攻击，对主目标首段基础伤害提高 20% | 只影响一张牌的一个目标与首段；任何实际参战者此前已警觉则不授予 |
| 成功出击命中仍在瞄准的弓手／蓄势法师 | 破势 | 带“打断”的牌，将主目标已公开且标记可打断的首个蓄势攻击意图替换为其保底行动 | 不删除目标正常回合；首领抗性与不可打断需明确显示 |
| 用架势迎战成功截住正在追击的目标 | 迎击 | 首张带“迎击”的防御牌，其自身基础护盾提高 20% | 真正出牌时才获盾；不从地图带入护盾，也不提升全队防御 |
| 目标已经戒备、稳固守点，或只有普通碰撞 | 无额外机会 | 正常使用攻击、破防或控制牌 | 主动完成仍可有顺序优势与准备牌，不保证额外破绽 |

20% 只是原型对比值，正式数值需结合牌费与首轮击杀率调整。突袭和迎击只修饰一张牌的对应基础量，再走正常伤害／护盾公式；不能对每个连击段、每个群体目标或每次派生伤害重复加成。首轮每张牌至多配置一种开场条款。

机会只能在 P 成功且玩家获得顺序优势时授予；交锋保留准备牌但不授予这些额外机会。只从当前装配能力明确支持且条件成立的机会中选择，多个同时成立则按“破势 → 迎击 → 突袭”选择一个，不叠加；基础迎战不支持这些机会。机会在匹配牌合法提交时消耗，最迟在玩家首回合结束或主目标首回合开始时消失；不能囤到后续回合、转移到另一只怪物或通过重洗重复触发。

“破势”需要怪物配置一个可公开的首个蓄势意图及保底行动。进入战斗时先正常生成并公开意图，再检查是否具备这一条件；没有对应意图、目标免疫或动作不可打断，就不生成可消费的破势机会，不能承诺打断一项实际不存在的技能。地图瞄准本身不会免费结算该攻击。打断牌仍可按普通目标规则使用，其正常效果与开场附加效果分别预览。

这里的机会是独立记录，不是护盾或普通持续状态。先按既有规则清除拥有者回合开始时的旧护盾、恢复资源和抽牌，玩家打出防御牌时才计算迎击加成，避免进战送盾又在首回合立即清空。

### 防止重置警戒刷突袭

每个怪物记录本刷新轮次是否曾针对玩家警觉。发起动作前先快照该记录，再发布本次动作的声光线索；本次出击引起的预警不会反过来抹掉合法突袭候选，但中止动作后留下的警觉记录会影响下一次尝试。归位可以解除追击和换装限制，不清除这项“已经交锋过”的记录；普通读档同样保留，休息刷新后才重置。

突袭还需检查**全部实际参战者**的动作前记录；用一只未醒的小怪作目标，不能让已经追击玩家的同伴一起变成毫无准备。归位怪物不提供额外突袭机会，不能靠反复绕门、拖到边界或取消施放稳定刷高额开场收益。

## 5. 典型构筑与怪物组合

| 玩家选择与怪物行为 | 地图结果 | 战斗结果 |
| --- | --- | --- |
| 刀剑构筑从巡卒背后完成短距突击，所有参战者此前未警觉 | P 完成，无 E，记录突袭候选 | 玩家首个回合提前，首手有一张对应攻击牌；是否利用 20% 条款仍取决于实际出牌 |
| 弓箭构筑先完成点射，目标尚未追到身边 | 被选目标直接参战，附近合法协战者一并判断 | 玩家先攻并准备射击牌；地图点射不先扣目标血量 |
| 法术构筑准备 1 秒引战，近战怪物 0.7 秒时已碰到玩家 | E 先完成，取消未完成术式 | 该怪物先攻，玩家首手正常随机，不授予未成功准备的法术 |
| 玩家打断技先于弓手瞄准完成，弓手有可打断的蓄势首意图 | 弓手作为玩家目标直接参战，不需等它瞄准完成 | 玩家先攻，付费打出匹配牌后才替换该意图；弓手仍有一次正常回合 |
| 玩家出击与怪物远程瞄准同一步完成 | 两者请求均有效，交锋 | 正常速度顺序；成功的玩家能力保留一张准备牌，无额外开场机会 |
| 防御构筑提前架势迎战追击守卫 | P 先完成，取得迎击机会 | 准备防御牌，首回合实际出牌时增加该牌护盾；无地图护盾 |
| 玩家攻击未警觉小怪，另一个已戒备近战怪物合法协战 | P 先完成，但参战者中已有警觉者 | 仍可玩家先攻与准备牌，不授予突袭机会，不推迟全体敌人回合 |
| 只有高费魔法牌且首回合魔法不足 | 高费术式不列为可用开战技，可用基础迎战 | 基础迎战成功可玩家先攻；不提前准备或免费释放高费牌 |

敌方先攻只提前一只发起者的正常回合；它按公开意图与正常资源限制行动，不另加免费射击、伤害倍率或全体玩家眩晕。玩家可以通过地图预警和主动能力减少被先攻；即使失败，其首个正常回合仍完整恢复与抽牌，不因被先攻少抽或少恢复。

## 6. 配置、反馈与落地

| 数据 | 需要记录的内容 |
| --- | --- |
| 开战技定义 | 稳定 ID、来源卡授权、地图范围／前摇／射击方式／动作声、准备牌引用、可支持的开场机会 |
| 玩家装配 | 一个开战技、来源装备与卡牌选择；基础迎战独立可用；预览首回合费用合法性 |
| 怪物扩展 | 本刷新轮次警觉记录、可打断首意图与保底行动、相关抗性、明确挑战入口是否允许主动出击 |
| 出击运行状态 | 主目标、前摇、动作开始前警觉快照、取消原因、再次出击间隔；不得用动画回调直接结算 |
| 遭遇上下文 | P／E／C 原因、合并名单、先攻者、准备牌真实副本、一个机会及主目标、随机状态与消费标记 |

界面显示当前开战技、来源卡、范围和准备效果；目标上显示有效射线与前摇，费用不满足时解释具体差额。入场先展示“玩家先攻／敌方先攻／交锋”、实际参战者及可知意图，再推进首轮。准备牌标明来源，卡面显示开场条款是否满足；预测只能使用可见信息，不能通过“可突袭”提示反推墙后有没有警觉同伴。

建议按三步验证：

1. 基础迎战、统一 P／E／C 判定及一次首轮排序；先确认不同输入和同时触发时结果一致。
2. 接入一个攻击、一个防御、一个低费法术来源，验证准备一张而仍然只抽 5 张，以及卡费和来源守恒。
3. 加入突袭、破势、迎击各一个实例，比较首轮击杀率、战损与不同构筑的可用性；参数不平衡时优先调整条款与前摇，不增加隐藏先手伤害。

| 验收情形 | 预期结果 |
| --- | --- |
| 混合装备、双持同名牌、卸下来源、无武器或只有辅助牌 | 候选来自明确授权；最多一个装配和一张准备牌；基础迎战始终可用，不造新卡 |
| 魔法牌费超过 M0 加恢复量，或入场后被增费 | 前者不能装配为该开战技；后者准备牌仍遵守真实费用，不免费、不透支 |
| 动作中移动取消、关门、失去目标或被较早敌方请求打断 | 清前摇与未完成准备，保留已引起警戒；无地图伤害或资源回合 |
| P 与多个 E 同步、玩家目标同时被接触、交换对象遍历顺序 | 一场战斗，名单去重且稳定；交锋走正常顺序，多个 E 不提前整群 |
| 开战前洗牌、首回合抽牌、只有 3 张牌、同名不同来源 | 准备的是一个真实副本；首回合仍抽至多 5 张；不重复、不虚构副本 |
| 玩家先攻或敌方先攻后推进两轮 | 首轮只移动一个正常回合，第二轮正常；资源与抽牌没有额外执行 |
| 迎击、群体牌、连击牌、无匹配牌或目标先行动 | 护盾在出牌时产生；附加收益不按段／目标复制；机会不能过期后触发 |
| 法师不可打断、目标意图不匹配或先被另一张牌击败 | 正确显示无机会或失效，不跳过整个敌人回合，不转移到其他敌人 |
| 多怪中只有一只未警觉、归位后重试、读档与休息刷新 | 突袭检查全部参战者；归位和读档不洗掉历史，休息刷新可重置 |
| 进入首领确认点、返回保护中按出击、战后读档奖励 | 默认挑战按正常入口；保护中不能出击；先攻、牌与奖励不重复生成 |

以上均为待执行验收。当前代码尚无战斗，本次没有实现地图攻击或修改实际卡牌配置；正式行动顺序、M0、卡费、首意图及开场条款数值需要随后在原型中共同收敛。
