# 区域地图与行动推进

> 当前方向及 Demo，2026-10-12。[返回概览](../00_游戏概览.md)

区域是可回访的地点网络。行动页一次只显示当前地点；点击场景边缘的出口前往相邻区域，不操作角色连续行走。M 打开的全区域地图仅供查看路线，不能点击移动。浏览、说明、切界面和思考均免费；移动及大部分场景行为消耗 1 行动步。没有现实时间倒计时。

```mermaid
graph LR
    A[入口营地·安全撤离] --- B[货运广场]
    A --- C[废料场]
    B --- C
    B --- D[临时工坊]
    C --- D
    C --- F[货运站·通电后撤离]
    D --- E[地下熔炉]
    E --- F
```

## 当前地点职责

| 地点 | 行动与价值 |
| --- | --- |
| 入口营地 | 免费安全撤离；不能治疗刷新、自由换装 |
| 货运广场 | 运输队、巡逻、两步保险箱与隐蔽接近 |
| 废料场 | 一次性补给搜索、修复货运站电源 |
| 临时工坊 | 启用后换装、随机临时祝福二选一 |
| 地下熔炉 | 永久调查、切警钟、挑战守卫 |
| 货运站 | 电源修复后免费撤离 |

Demo 全图公开，地点和连接固定。正式设计可分层揭示地标、支路与装备来源，但不能依赖实时视野、碰撞或遮挡判定接战。

移动先改变地点，再推进巡逻。离开广场解除当次锁定，回到有巡逻的广场会重新预警，不会落地自动连战。已完成交互不能重复提交，已清除敌人不在本局刷新。

## 局势

巡逻起始距广场 4 步。普通行动使其减少一步；剩 1 步显示到达预警，到达后守在广场。保险箱首步噪声会让巡逻立即抵达。详情见[接战规则](03_遭遇事件与交互节点.md)。

行动数决定平静、戒备和封锁三个威胁阶段。Demo 仅增强新遭遇攻击，没有随机封路。基础出口始终可用。正式版可增加阶段事件和高价值目标，但需要预先公开变化。

## 长行动与内容边界

保险箱采用两次独立点击，每次一步。第一步后自动停下，展示新预警，由玩家决定是否继续；没有后台自动续做。其余当前行动均为一步。

原型不实现背包容量、多格路程、随机地形、快速行进或装备地图能力。未来装备能力必须显式配置，并为必经目标提供通用替代解法。
