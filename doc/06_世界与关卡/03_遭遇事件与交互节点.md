# 主动接战、敌人预警与搜索中断

> 当前方案，2026-10-12。[返回概览](../00_游戏概览.md)

## 接战状态

敌人按行动步推进，不按画面时间移动。当前巡逻以剩余步数表达接近，在广场到达后锁定，再给一次应对机会。

| 状态 | 明确信息 | 玩家选择 |
| --- | --- | --- |
| 接近 | 距广场 N 步 | 搜索、绕行或提前迎战运输队 |
| 即将到达 | 下一步抵达 | 离开或尽快锁定当前遭遇 |
| 锁定 | 再留在广场行动一次会接战 | 离开、主动迎战、治疗后应战或冒险继续搜索 |
| 接战 | 名单与原因固定 | 进入卡牌战斗，场外暂停 |

驻守运输队和首领不会自动追击；它们是主动挑战对象。巡逻是 Demo 的主动接敌单位。正式版可拓展怀疑、噪声调查和敌方远程蓄势，但目前不模拟独立射线、距离或实时前摇。

## 主动出击

直接迎战计 1 行动，但先锁定当前敌方名单，不让尚未抵达的巡逻因为这次点击加入。攻击运输队时，已经抵达且未击败的巡逻协战；直接挑战巡逻时运输队不协战。首领是否带警钟护卫由设施状态决定。

隐蔽接近消耗 1 步，照常推进巡逻。没有被拦截才获得准备；离开地点取消准备。准备收益是一张当前武器真实副本进入首回合五张手牌，不额外增牌。若接近步骤导致敌方到达，玩家会看到锁定；准备不会阻止敌人协战。

## 行动提交顺序

普通行动：校验 → 玩家行为或进度 → 区域步数及巡逻 → 接战判定 → 呈现并保存。治疗会先消耗补给、回血，再接受预告的拦截。

保险箱首步：记录进度 1/2、产生噪声、到达锁定、停止等待下一次输入。保险箱后续步骤遇到既有锁定时，敌人先拦截，保留进度 1/2，不完成搜索、不生成奖励。打败巡逻后可以继续第二步，成功才生成一次物品。

移动：先离开旧地点，再更新敌人；从而允许在锁定后逃离广场。长行动每步分别提交，不会在玩家未再次确认时跨过预警。

## 开场与战后

无视锁定被拦截时，巡逻首回合护盾 +4。正常主动迎战不获额外回合。双方没有依赖鼠标速度的同时完成判定。

战斗期间区域步数、巡逻和其他敌人冻结。结算后不自动推进场景，玩家拥有新的决策窗口；不会因结束战斗立即再被接战。已参与巡逻被击败则锁定风险移除，尚未参与者保持原来的进度。

无效操作不扣资源、不推进步数。任何一次性交互或已完成遭遇重复请求都返回失败，不再次生成收获。
